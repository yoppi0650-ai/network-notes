# ネットワーク学習ノート

ネットワークスペシャリスト試験（以降ネスペ）対策を兼ねたネットワーク技術学習ノート。ネスペの過去問などを題材として扱いながら、ネットワークについて体系的に学んでいく。

## 過去問

- `past-exams/`に、H21(2009)からR7(2025)のうち、コロナで試験が実施されなかったR2(2020)を除いた16年分の公式過去問を配置。
- `past-exams/download-nw-exams.ps1`は、公式サイトからの過去問一括ダウンロード用PowerShellスクリプト
- 試験は、すべて60点以上で合格

## AM学習の進め方

H21〜R7の16年分・午前I 480問＋午前II 400問をすべて分野分類した結果に基づく、**最低限読むべきノートと読む順番**。年平均は「16年の出題数 ÷ 16」で、各ノートの出典欄と対応している。

### 前提：午前Iの免除があるかを先に確認する

応用情報技術者試験の合格、または高度試験・情報処理安全確保支援士試験の合格や午前I突破の実績があると、一定期間は午前Iが免除される（条件と期間はIPAの受験案内を確認）。**免除の有無で読む量が1.4倍ほど変わる**うえ、優先順位も変わるので、ここを最初に確定させる。

- **免除あり** → [午前IIの読む順番](#午前iiは狭く深くで勝てる)の20本（約6,500行）で足りる。
- **免除なし** → 午前Iは23分野から満遍なく出るため、上記に加えて[さらに9本](#午前iは広く浅くしかない)（約2,800行）が要る。

### 午前IIは「狭く深く」で勝てる

### 午前Iは「広く浅く」しかない

午前Iは**30問・18問正解で合格**。23分野から満遍なく出るため、最多の分野11でも年3.5問にしかならない。「どこを捨てるか」ではなく「**どこから埋めるか**」の勝負になる。

ただし、午前IIのために読んだ20本は午前Iでも効く。**20本を読み終えた時点で午前Iは年10.1問/30**（33.5%）まで来ている。ここから出題数の多い順に**9本**足せば合格ラインを超える。

ただし **18.6問は「16年の平均で」**という値であり、特定の年に18問取れる保証ではない。合格ラインぎりぎりを狙う設計は危険なので、**余裕をみるなら残りの分野にも一通り目を通しておきたい**。全91ノートを読めば理屈のうえでは30問すべてが守備範囲に入る。

なお午前Iは、マネジメント系（分野14〜16）が年4.8問、ストラテジ系（分野17〜23）が年7.4問で、**合わせて年12.1問＝30問の4割**を占める。技術者には馴染みが薄い領域だが、**計算と暗記で確実に取れる**ぶん費用対効果は高い。テクノロジ系で落とす分をここで補う戦略が有効である。

### 読み終えたら過去問に戻る

午前試験は過去問の再利用が多い。ノートを一周したら `past-exams/` の問題を年度順に解き、間違えた設問が属するノートの該当節に戻る。各ノートの節末には**出典（出題年度・試験区分・問題番号）**をまとめてあるので、解いた問題から逆引きできる。
