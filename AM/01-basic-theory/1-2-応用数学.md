# 1-2 応用数学

確率・統計と数値計算を扱う。[1-1 離散数学](1-1-離散数学.md) が「とびとびの値」の数学だったのに対し、こちらは**連続量や不確かさを扱う数学**である。

情報処理試験でこの分野が問われるのは、**コンピュータが扱う数値が有限であることの帰結**（計算誤差）と、**測定や予測に伴う不確かさの扱い**（確率・統計）が、どちらも実務の判断に直結するからである。システムの性能評価（→ [4-2 システムの評価指標](../04-system-components/4-2-システムの評価指標.md)）、通信の誤り率（→ [1-4 通信に関する理論](1-4-通信に関する理論.md)）、データ分析（→ [22-2 業務分析・データ利活用](../22-corporate-activities/22-2-業務分析-データ利活用.md)）はいずれもこの章の内容を土台にしている。

## 1. 数値計算の誤差

コンピュータは有限桁でしか数を扱えないので、計算には必ず誤差が伴う。誤差は**原因ごとに名前が付いている**。

| 誤差 | 発生の仕方 |
| --- | --- |
| **桁落ち** | **値がほぼ等しい二つの数値の差を求めたとき、有効桁数が減ることによって発生する** |
| **情報落ち** | **絶対値の非常に大きな数値と小さな数値の加算や減算を行ったとき、小さい数値が計算結果に反映されないことによって発生する** |
| **丸め誤差** | **指定された有効桁数で演算結果を表すために、切捨て・切上げ・四捨五入などで下位の桁を削除することによって発生する** |
| **打切り誤差** | **無限級数で表される数値の計算処理を有限項で打ち切ったことによって発生する** |
| オーバフロー／アンダーフロー | 表現できる範囲を超えた／下回った |

### 1.1 桁落ち

有効数字4桁で $1.234 \times 10^{3}$ と $1.233 \times 10^{3}$ の差を取ると、

$$ 1.234 \times 10^3 - 1.233 \times 10^3 = 0.001 \times 10^3 = 1.000 \times 10^0 $$

結果の有効数字は**実質1桁**になってしまう。元の数値の下位にあった不確かさが、そのまま結果全体の不確かさになるからである。これが**桁落ち**である。

桁落ちが厄介なのは、**計算自体は正しく行われているのに精度が失われる**点である。二次方程式の解の公式で $b^2 - 4ac$ が小さいときなどに顕著に現れる。対策としては、式を変形して「近い値どうしの引き算」を避ける（有理化するなど）方法が取られる。

### 1.2 情報落ち

$1.000 \times 10^{10}$ に $1.000 \times 10^{-5}$ を足しても、有効数字4桁では $1.000 \times 10^{10}$ のままである。小さいほうの数値が**表現できる桁の外に落ちてしまう**。これが**情報落ち**である。

多数の数値を合計するとき、大きい値から順に足していくと情報落ちが累積する。**小さい値から順に足す**と誤差を抑えられる、という実務的な工夫がある。

4つの誤差は**原因で区別する**。「近い値の差」が桁落ち、「大小差のある加減算」が情報落ち、「桁を切る」が丸め誤差、「無限を有限で打ち切る」が打切り誤差である。

> **出題** 桁落ち: H25午前I問1

## 2. 確率

### 2.1 基本の規則

| 規則 | 式 | 適用条件 |
| --- | --- | --- |
| 積の法則 | $P(A \cap B) = P(A) \times P(B)$ | $A$ と $B$ が独立 |
| 和の法則 | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ | 常に成り立つ |
| 余事象 | $P(\overline{A}) = 1 - P(A)$ | 常に成り立つ |

**余事象を使う**のが計算を簡単にする定石である。「少なくとも1つが〜」という問いは、「1つも〜でない」確率を1から引くと場合分けが要らなくなる。システムの稼働率計算で並列構成を $1 - (1-a)(1-b)$ と表すのが典型例である（→ [4-2 システムの評価指標](../04-system-components/4-2-システムの評価指標.md)）。

### 2.2 期待値

確率変数 $X$ が値 $x_i$ を確率 $p_i$ でとるとき、期待値は

$$ E[X] = \sum_i x_i p_i $$

で定義される。「平均してどれくらいになるか」を表す。

期待値の計算は分野を越えて現れる。**通信の誤り発生数**（→ [1-4 通信に関する理論](1-4-通信に関する理論.md)）、**平均CPI**（→ [3-1 プロセッサ](../03-computer-components/3-1-プロセッサ.md)）、**プロジェクトの期待金額価値**（→ [14-8 プロジェクトのリスク](../14-project-management/14-8-プロジェクトのリスク.md)）は、いずれも「値 × 確率（または構成比）の総和」という同じ形をしている。

### 2.3 ポアソン分布と指数分布

待ち行列理論（→ [4-2](../04-system-components/4-2-システムの評価指標.md)）で前提になる2つの分布を押さえておく。

| 分布 | 何を表すか |
| --- | --- |
| **ポアソン分布** | 一定時間に**ランダムに発生する事象の件数**。到着の分布 |
| **指数分布** | 事象と事象の**間隔**、またはサービス時間 |

「客の到着がポアソン分布に従い、サービス時間が指数分布に従う」というのがM/M/1モデルの前提である。これは「次に何が起きるかが、過去の経過と無関係である」という性質（無記憶性）を仮定していることを意味する。

## 3. 統計

### 3.1 代表値とばらつき

| 指標 | 意味 |
| --- | --- |
| 平均値 | 全データの総和をデータ数で割った値 |
| 中央値（メジアン） | 順に並べたときの中央の値。外れ値の影響を受けにくい |
| 最頻値（モード） | 最も多く現れる値 |
| 分散 | 平均からの差の2乗の平均 |
| **標準偏差** | 分散の平方根。**データのばらつきの大きさ**を、元のデータと同じ単位で表す |

**平均値だけでは分布は語れない**。平均点が同じ2つの教科でも、全員が平均付近に固まっている場合と、高得点者と低得点者に二分されている場合とでは意味がまったく違う。この違いを表すのが標準偏差である。

### 3.2 相関係数

2つの変量の**直線的な関係の強さ**を $-1$ から $+1$ の範囲で表す指標である。

| 相関係数 | 意味 |
| --- | --- |
| **$+1$** | **全ての標本点が正の傾きをもつ直線上にある**（完全な正の相関） |
| $0$ に近い | 直線的な関係がない（**無相関**） |
| $-1$ | 全ての標本点が負の傾きをもつ直線上にある（完全な負の相関） |

正しい記述は、

> **全ての標本点が正の傾きをもつ直線上にあるとき、相関係数が +1 になる。**

誤答として並ぶ記述を確認する。

| 記述 | 誤りの理由 |
| --- | --- |
| 変量間の関係が線形のときは、相関係数が0になる | **逆**。線形関係が強いほど $\pm 1$ に近づく |
| 変量間の関係が非線形のときは、相関係数が負になる | 非線形なら $0$ に近い値になりうるが、負とは限らない |
| 無相関のときは、相関係数が $-1$ になる | **無相関なら 0**。$-1$ は完全な負の相関 |

**相関係数が測るのは直線的な関係だけ**という点が重要である。きれいな放物線を描く関係（完全な法則性がある）でも、相関係数はほぼ0になりうる。「相関係数が0だから関係がない」とは言えないし、「相関が高いから因果関係がある」とも言えない。

> **出題** 相関係数: H29午前I問1

## 4. 正規分布

**正規分布**は、平均を中心に左右対称の釣鐘型をした分布である。自然現象や測定値の多くがこの形に近づくことが知られており、統計の基礎になっている。

### 4.1 形を決める2つのパラメタ

| パラメタ | 形への影響 |
| --- | --- |
| **平均 $\mu$** | 山の**位置**（左右の位置） |
| **標準偏差 $\sigma$** | 山の**広がり**。小さいほど尖り、大きいほどなだらかになる |

グラフを選ぶ設問では、**「山の頂点が平均の位置にあるか」**と**「広がりが標準偏差と整合するか」**の2点を確認する。平均60、標準偏差10なら、頂点は60にあり、おおよそ $60 \pm 10$（50〜70）の範囲に全体の約68%が収まる形になる。

### 4.2 標準化（偏差値の考え方）

異なる平均・標準偏差をもつ分布を比較するには、**標準化**して同じ土俵に乗せる。

$$ z = \frac{x - \mu}{\sigma} $$

$z$ は「平均から標準偏差何個分離れているか」を表す。$z$ が同じなら、分布の中での位置づけは同じになる。

**例題：どの教科に高得点者が多いか**

> 受験者1,000人の4教科のテスト結果は表のとおりで、いずれも正規分布に従う。**90点以上の得点者が最も多かった**と推定できる教科はどれか。

| 教科 | 平均点 | 標準偏差 |
| --- | --- | --- |
| A | 45 | 18 |
| B | 60 | 15 |
| C | 70 | 8 |
| D | 75 | 5 |

90点を標準化した値 $z$ を各教科で計算する。

| 教科 | $z = \dfrac{90 - \mu}{\sigma}$ |
| --- | --- |
| A | $(90-45)/18 = 2.50$ |
| **B** | $(90-60)/15 = \mathbf{2.00}$ |
| C | $(90-70)/8 = 2.50$ |
| D | $(90-75)/5 = 3.00$ |

**$z$ が小さいほど「90点」は平均に近く、それ以上の人が多い**。最小は B の $2.00$ なので、答えは **B** である。

平均点だけを見ると D（75点）が最も高いので「Dが有利そうだ」と考えてしまうが、Dは標準偏差が5と小さく、点数が平均付近に密集している。したがって90点という平均から15点も離れた得点に達する人は少ない。**平均が高いことと、特定の高得点者が多いことは別**だという点が、この問題の核心である。

> **出題** 正規分布と標準偏差: H30午前I問3 ｜ 正規分布のグラフ: R5午前I問2

## この章のまとめ

- 誤差は**原因で区別する**。**桁落ち＝近い値の差で有効桁数が減る**、情報落ち＝大小差のある加減算で小さい値が消える、丸め誤差＝桁を切る、打切り誤差＝無限級数を有限で打ち切る。
- 確率では**余事象を使って場合分けを避ける**のが定石。**期待値は「値 × 確率」の総和**で、分野を越えて同じ形が現れる。
- **相関係数は直線的な関係の強さ**を $-1$〜$+1$ で表す。**無相関は0**であり、$-1$ ではない。非線形な関係は相関係数では捉えられない。
- 正規分布は**平均が位置、標準偏差が広がり**を決める。**標準化 $z = (x-\mu)/\sigma$ で異なる分布を比較できる**。平均が高くても標準偏差が小さければ、高得点者は少ない。
