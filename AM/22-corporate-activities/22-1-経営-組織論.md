# 22-1 経営・組織論

企業の**組織のあり方と、人を動かす考え方**を扱う。

情報処理技術者試験でこの分野が問われるのは、**システムは組織の中で使われる**からである。どれだけ優れたシステムでも、組織構造や指揮命令系統と噛み合わなければ機能しない。[14-5 プロジェクトの資源](../14-project-management/14-5-プロジェクトの資源.md) で見たマトリックス組織の板挟み問題も、組織論の知識がなければ理解できない。

午前Iの問29前後から出題される。16年で1問。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、組織形態とリーダシップ論の整理を補っている。

## 1. 組織の形態

| 形態 | 構成 | 特徴 |
| --- | --- | --- |
| **職能別組織（機能別組織）** | 製造、営業、経理など**機能ごと**に分ける | 専門性が高まる。部門間の調整が難しい |
| **事業部制組織** | 製品、地域、顧客など**事業ごと**に分ける | 事業単位で意思決定が速い。機能が重複する |
| **マトリックス組織** | **機能と事業の両方**の軸をもつ | 両方の利点を得られるが、**命令系統が二重になる** |
| **プロジェクト組織** | 目的達成のために一時的に編成する | 目的に集中できる。解散後の人員配置が課題 |
| **カンパニー制** | 事業部を独立した会社のように扱う | 責任と権限が明確。全社最適が難しい |
| **フラット型組織** | **階層をできるだけ少なくする** | **意思決定が速い**。管理の負荷が集中しうる |

**どの形態にも固有の弱点がある**というのが組織論の前提である。職能別は調整が難しく、事業部制は重複が生じ、マトリックスは板挟みを生む。組織形態の選択は、**どの弱点なら許容できるか**の判断になる。

[14-5 プロジェクトの資源](../14-project-management/14-5-プロジェクトの資源.md) で見たとおり、プロジェクトマネージャの権限の強さは組織形態で決まる。機能型では弱く、プロジェクト型では強い。マトリックス型ではその中間で、**権限の範囲を事前に明確にしておく**必要が生じる。

## 2. リーダシップ論

リーダシップの研究は、**何に注目するか**で発展してきた。

| 理論 | 注目するもの |
| --- | --- |
| **特性理論** | **優れたリーダシップを発揮するリーダ個人がもつ性格、知性、外観などの個人的資質** |
| **行動理論（PM理論など）** | **リーダの行動のスタイル** |
| **条件適応理論（状況理論）** | **状況によって有効なリーダシップが変わる**という考え方 |

### 2.1 PM理論

> リーダシップ論のうち、**PM理論の特徴**はどれか。

答えは、

> **リーダシップのスタイルについて、目標達成能力と集団維持能力の二つの次元に焦点を当てている。**

**PM理論の「P」と「M」は2つの機能を表す**。

| 記号 | 機能 | 内容 |
| --- | --- | --- |
| **P**（Performance） | **目標達成機能** | 目標を示し、計画を立て、成果を出させる |
| **M**（Maintenance） | **集団維持機能** | 人間関係に配慮し、チームをまとめる |

この2軸の強弱から4類型（PM型、Pm型、pM型、pm型）に分類し、**両方が強いPM型が最も望ましい**とする。

**2軸に分けたことの意義**は、「成果を出すリーダ」と「人望のあるリーダ」が対立するものではないと示した点にある。どちらか一方だけでは持続しない。成果だけを求めればチームが疲弊し、関係だけを重んじれば成果が出ない。

誤答として並ぶ理論との区別を押さえる。

| 記述 | 理論 |
| --- | --- |
| リーダ個人がもつ**性格、知性、外観などの個人的資質**の分析に焦点を当てる | **特性理論** |
| **目標達成能力と集団維持能力の二つの次元**に焦点を当てる | **PM理論** |
| 有効性は**部下の成熟（自律性）の度合い**という状況要因に依存する | **SL理論**（状況対応リーダシップ理論） |
| 有効性は、リーダのパーソナリティと、**統制力や影響力を行使できるかという状況要因**に依存する | **フィードラーの条件適応理論** |

**「二つの次元」という語があればPM理論**である。「状況要因に依存する」という記述が入っていれば条件適応理論の系統になる。

> **出題** PM理論: R4午前I問29

## 3. 企業活動と社会的責任

### 3.1 企業統治

| 用語 | 内容 |
| --- | --- |
| **コーポレートガバナンス** | 企業統治。経営者を監督し、健全な経営を確保する仕組み |
| **内部統制** | 業務の適正を確保する仕組み（→ [16-2 内部統制](../16-system-audit/16-2-内部統制.md)） |
| **コンプライアンス** | 法令遵守。法令だけでなく社会規範も含む |

**コーポレートガバナンスと内部統制は向きが違う**。ガバナンスは**経営者を外から監督する**仕組み（株主、取締役会、監査役）であり、内部統制は**経営者が組織の中に組み込む**仕組みである。ITガバナンスも同じ構造で、情報システムを経営の視点から統治する枠組みになる（→ [16-1 システム監査](../16-system-audit/16-1-システム監査.md)）。

### 3.2 CSRとサステナビリティ

| 用語 | 内容 |
| --- | --- |
| **CSR** | 企業の社会的責任。経済的責任だけでなく、環境や社会への責任を果たす |
| **SDGs** | 持続可能な開発目標 |
| **ESG投資** | 環境（Environment）・社会（Social）・ガバナンス（Governance）を考慮した投資 |
| **ダイバーシティ** | 多様な人材を活かす（→ [21-1 ビジネスシステム](../21-business-and-industry/21-1-ビジネスシステム.md)） |

これらが経営課題になるのは、**理念の問題であると同時に、実利の問題でもある**からである。ESG投資の拡大により、環境や人権への対応が資金調達の条件になりつつある。[18-3 調達計画及び実施](../18-system-planning/18-3-調達計画及び実施.md) で見たグリーン調達・CSR調達は、この圧力が取引先にまで及ぶことを示している。

### 3.3 ナレッジマネジメント

**ナレッジマネジメント**は、**企業内に散在している知識を共有化し、全体の問題解決力を高めていく経営**である（→ [19-1 経営戦略手法](../19-business-strategy-management/19-1-経営戦略手法.md) のベンチマーキングの誤答として登場する）。

鍵になるのは、**暗黙知と形式知の区別**である。

| 種類 | 性質 |
| --- | --- |
| **暗黙知** | 言葉にしにくい、個人の経験に根ざした知識 |
| **形式知** | 文書や数値で表現できる知識 |

**ナレッジマネジメントの難しさは、価値のある知識ほど暗黙知である**ことにある。手順書に書ける知識は共有しやすいが、熟練者の判断や勘所は言語化が難しい。暗黙知を形式知に変換し（表出化）、共有し、再び個人の実践を通じて暗黙知に戻す（内面化）という循環（SECIモデル）が提唱されているのは、この困難に向き合うためである。

## この章のまとめ

- 組織形態には**それぞれ固有の弱点がある**。職能別は調整の難しさ、事業部制は機能の重複、マトリックスは命令系統の二重化。選択は「どの弱点なら許容できるか」の判断になる。
- **PM理論は目標達成機能（P）と集団維持機能（M）の2次元**でリーダシップを捉える。「二つの次元」が決め手。特性理論は個人の資質、SL理論やフィードラー理論は状況要因に注目する。
- **コーポレートガバナンスは経営者を外から監督、内部統制は経営者が組織に組み込む**仕組み。
- **ナレッジマネジメントの難しさは、価値のある知識ほど暗黙知である**点にある。
