# 22-2 業務分析・データ利活用

業務の課題を**データと図法で分析する**手法を扱う。

この分野の手法は数が多いが、**何を明らかにしたいのか**で整理できる。要因の関係を明らかにしたいのか、意見をまとめたいのか、集団を分類したいのか、不確実な状況で意思決定したいのか。目的が決まれば使う道具も決まる。

## 1. QC七つ道具と新QC七つ道具

品質管理の分析図法は2系統ある。**数値データを扱うのがQC七つ道具、言語データを扱うのが新QC七つ道具**である。

| 系統 | 扱うもの | 主な図法 |
| --- | --- | --- |
| **QC七つ道具** | **数値データ** | パレート図、**特性要因図**、**散布図**、**ヒストグラム**、管理図、チェックシート、層別 |
| **新QC七つ道具** | **言語データ** | **親和図**、**連関図**、系統図、**マトリックス図**、アローダイアグラム、PDPC法、マトリックスデータ解析法 |

### 1.1 親和図

> **親和図の特徴**はどれか。

答えは、

> **錯綜した問題点や、まとまっていない意見、アイディアなどを整理し、まとめるために用いられる。**

**親和図は「ばらばらの言語データをグループにまとめる」**図法である。ブレーンストーミングなどで出た大量の意見を、似たもの同士にまとめ、各グループに見出しを付けて全体像を整理する。**KJ法**として知られる手法と同系統である。

誤答として並ぶ図法との区別を押さえる。

| 記述 | 図法 |
| --- | --- |
| **原因と結果を対比させた図式表現**であり、不良原因の追及に用いられる | **特性要因図**（魚の骨図） |
| **錯綜した問題点やまとまっていない意見を整理し、まとめる** | **親和図** |
| **二つ以上の変数の相互関係**を表すのに役立つ | **散布図** |
| **分布の形、目標値からのばらつき状態**から、製品の品質が規格値に対して満足いくものかを判断する | **ヒストグラム** |

### 1.2 連関図

> 分析対象としている問題に**数多くの要因が関係し、それらが相互に絡み合っている**とき、**原因と結果、目的と手段といった関係を追求**していくことによって、**因果関係を明らかにし、解決の糸口をつかむ**ための図はどれか。

答えは **連関図**である。

**特性要因図と連関図の違い**が、この2問を分ける鍵になる。

| 図法 | 構造 | 適する状況 |
| --- | --- | --- |
| **特性要因図** | **1つの結果に対して、要因を階層的に整理する**（魚の骨の形） | 要因が階層的に整理できる |
| **連関図** | **要因どうしが相互に絡み合う**関係を網状に表す | **要因が相互に影響し合い、階層にならない** |

特性要因図は「結果 ← 大要因 ← 中要因 ← 小要因」と**一方向の木構造**になる。しかし現実の問題では、要因Aが要因Bを生み、Bがまた別の経路でAを悪化させる、といった**循環や相互作用**がある。これを表現できるのが連関図である。

設問に**「相互に絡み合っている」「原因と結果、目的と手段といった関係を追求」**とあれば連関図を選ぶ。

誤答として並ぶ図法も確認する。

| 図法 | 用途 |
| --- | --- |
| **アローダイアグラム** | 作業の順序と日程（→ [14-6 プロジェクトの時間](../14-project-management/14-6-プロジェクトの時間.md)） |
| **パレート図** | 件数の多い順に並べ、重点管理する対象を選ぶ |
| **マトリックス図** | 2つの要素の対応関係を表に整理する |
| **連関図** | 要因の相互の因果関係を網状に表す |

> **出題** 親和図: H24午前I問29 ｜ 連関図: H26午前I問29

## 2. 統計的な分析手法

> 観測データを**類似性によって集団や群に分類し、その特徴となる要因を分析する手法**はどれか。

答えは **クラスタ分析法**である。

**「類似性で分類する」**のがクラスタ分析である。あらかじめ分類の正解が与えられていない点が重要で、[1-3 情報に関する理論](../01-basic-theory/1-3-情報に関する理論.md) で見た**教師なし学習のクラスタリング**と同じ手法を指す。顧客を購買傾向で分類し、セグメントごとの施策を考える、といった使い方をする（→ [19-2 マーケティング](../19-business-strategy-management/19-2-マーケティング.md)）。

誤答として並ぶ手法との区別を押さえる。

| 手法 | 内容 |
| --- | --- |
| **クラスタ分析法** | **類似性によって集団や群に分類する** |
| **指数平滑法** | 過去のデータに指数的に減衰する重みを付けて将来を予測する |
| **デルファイ法** | 専門家へのアンケートを繰り返して意見を収束させる（→ [20-1 技術開発戦略の立案](../20-technology-strategy-management/20-1-技術開発戦略の立案.md)） |
| **モンテカルロ法** | 乱数を使ったシミュレーションで解を推定する |

その他の主な手法も整理しておく。

| 手法 | 用途 |
| --- | --- |
| 回帰分析 | 変数間の関係を式で表し、予測する |
| 相関分析 | 2変数の関係の強さを測る（→ [1-2 応用数学](../01-basic-theory/1-2-応用数学.md)） |
| **ABC分析** | 累積構成比でA・B・Cに分類し、重点管理する。パレート図を使う |
| 主成分分析 | 多数の変数を少数の合成変数にまとめる |
| 線形計画法 | 制約条件のもとで目的関数を最大化・最小化する |
| **在庫問題** | 経済的発注量（EOQ）などを求める |

> **出題** クラスタ分析: H22午前I問26、H30午前I問26

## 3. 不確実性下の意思決定

将来が不確実なとき、どの案を選ぶかの基準がいくつかある。

| 原理 | 考え方 |
| --- | --- |
| **マクシミン原理** | **各案の最悪の結果を比べ、その中で最大のものを選ぶ**（悲観的・保守的） |
| **マクシマックス原理** | **各案の最良の結果を比べ、その中で最大のものを選ぶ**（楽観的） |
| ラプラス原理 | 各状態が等確率と仮定して期待値を比べる |
| ミニマックスリグレット原理 | 後悔（最良の選択との差）の最大値が最小の案を選ぶ |

### 3.1 計算例

> 来期の景気動向について、悪化・横ばい・好転の三つの意見に完全に分かれた。来期の投資計画について、積極的投資・継続的投資・消極的投資のいずれかに決定しなければならない。表の予想利益については意見が一致した。意思決定に関する記述のうち適切なものはどれか。
>
> | 予想利益（万円） | 悪化 | 横ばい | 好転 |
> | --- | --- | --- | --- |
> | 積極的投資 | 50 | 150 | 500 |
> | 継続的投資 | 100 | 200 | 300 |
> | 消極的投資 | 400 | 250 | 200 |

**マクシミン原理**で解く。各案の**最小値**を求め、その中で最大のものを選ぶ。

| 投資計画 | 最小値 |
| --- | --- |
| 積極的投資 | $\min(50, 150, 500) = 50$ |
| 継続的投資 | $\min(100, 200, 300) = 100$ |
| **消極的投資** | $\min(400, 250, 200) = \mathbf{200}$ ← 最大 |

したがって**マクシミン原理に基づく最適意思決定は消極的投資**となる。

参考に**マクシマックス原理**でも計算してみる。各案の**最大値**を求め、その中で最大のものを選ぶ。

| 投資計画 | 最大値 |
| --- | --- |
| **積極的投資** | $\max(50, 150, 500) = \mathbf{500}$ ← 最大 |
| 継続的投資 | $\max(100, 200, 300) = 300$ |
| 消極的投資 | $\max(400, 250, 200) = 400$ |

マクシマックスでは**積極的投資**になる。「マクシマックス原理に基づく最適意思決定は継続的投資である」という選択肢は誤りである。

**同じ表から、採用する原理によって正反対の結論が出る**点がこの問題の要点である。どの原理を使うかは、**意思決定者がリスクをどう捉えるか**という価値判断であり、計算では決まらない。

**用語の覚え方**は、**マクシミン＝「ミニ（最小）」をマックスに、マクシマックス＝「マックス（最大）」をマックスに**と分解すると取り違えない。

### 3.2 期待値を使う場合

確率が分かっている場合は、期待値で比較する。[14-8 プロジェクトのリスク](../14-project-management/14-8-プロジェクトのリスク.md) の期待金額価値がこれにあたる。本問のように**確率が分からない（意見が分かれている）場合**に、マクシミンやマクシマックスといった原理が使われる。

> **出題** 不確実性下の意思決定: H23午前I問29、H27午前I問29

## 4. BI

> **BI（Business Intelligence）の活用事例**として適切なものはどれか。

答えは、

> **業績の評価や経営戦略の策定を行うために、業務システムなどに蓄積された膨大なデータを分析する。**

**BIは「社内に蓄積されたデータを経営判断に使う」**ことである。**データの出どころが社内の業務システム**である点が決め手になる。

誤答として並ぶ記述を確認する。

| 記述 | 実際は何か |
| --- | --- |
| 競合他社が発行するアニュアルレポートなどの**刊行物を入手**し、経営戦略や財務状況を把握する | **競合情報の収集**。社外の公開情報であり、BIの対象ではない |
| **業務システムなどに蓄積された膨大なデータを分析**し、業績評価や経営戦略の策定を行う | **BI** |
| 電子化された学習教材をネットワーク経由で利用し、学習・成績管理を行う | **eラーニング** |
| りん議や決裁など日常の定型的業務を電子化する | **ワークフローシステム** |

BIを支える技術基盤が、[9-5 データベース応用](../09-database/9-5-データベース応用.md) で扱ったデータウェアハウス、データマート、OLAP、データマイニングである。

| 層 | 役割 |
| --- | --- |
| データウェアハウス | 業務システムのデータを蓄積する |
| OLAP | 対話的に多次元分析する（仮説を確かめる） |
| データマイニング | 隠れた規則を発見する（仮説なしに探す） |
| **BI** | **これらを使って経営判断を支援する** |

**BIは「経営判断に使う」という目的の名前**であり、特定の技術を指すのではない。技術としてはDWHやOLAPを使い、分析手法としては本章の統計手法を使う。

> **出題** BI: H28午前I問24

## この章のまとめ

- 分析図法は**数値データのQC七つ道具と、言語データの新QC七つ道具**に分かれる。
- **親和図はばらばらの意見をグループにまとめる**。**特性要因図は1つの結果に要因を階層的に整理**、**連関図は要因が相互に絡み合う関係を網状に表す**。「相互に絡み合う」なら連関図。
- **クラスタ分析は類似性によって集団に分類する**。教師なし学習のクラスタリングと同じ考え方。
- **マクシミンは最悪の結果の中で最良、マクシマックスは最良の結果の中で最良**を選ぶ。同じ表でも原理によって結論が逆になる。
- **BIは社内の業務システムに蓄積されたデータを経営判断に使うこと**。社外の刊行物の収集は含まない。
