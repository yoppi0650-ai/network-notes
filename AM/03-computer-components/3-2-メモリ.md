# 3-2 メモリ

記憶装置の階層と、その中核であるキャッシュメモリ・主記憶を扱う。

この分野を貫く考え方は**記憶階層**である。「速いメモリは高価で小さい、遅いメモリは安価で大きい」という物理的・経済的な制約のもとで、**速いメモリの容量しかないのに、遅いメモリの容量があるかのように見せる**のがキャッシュと仮想記憶の目的である。この「見せかけ」を支えるのが**局所性**という性質であり、本章の技術はすべてここから説明がつく。

午前IIでは問22前後から、午前Iでは問4前後から出題される。**キャッシュの平均アクセス時間（4回）**と**メモリインタリーブ（4回）**が二大頻出テーマである。

## 1. 記憶階層と局所性

記憶装置は、速度・容量・単価の異なるものを階層状に組み合わせて使う。

| 階層 | 速度 | 容量 | 単価 |
| --- | --- | --- | --- |
| レジスタ | 最速 | 最小 | 最高 |
| キャッシュメモリ（SRAM） | 速い | 小さい | 高い |
| 主記憶（DRAM） | 中 | 中 | 中 |
| 補助記憶（SSD、磁気ディスク） | 遅い | 大きい | 安い |

この階層が機能するのは、プログラムのメモリアクセスに**局所性**があるからである。

- **時間的局所性**：一度アクセスしたデータは、近いうちに再びアクセスされやすい（ループ変数など）
- **空間的局所性**：あるアドレスにアクセスしたら、その近くのアドレスもアクセスされやすい（配列の走査、連続する命令など）

もしアクセスが完全にランダムなら、小さな高速メモリを置いても当たる確率は容量比だけになり、ほとんど効果がない。局所性があるからこそ、**全体のごく一部を高速メモリに置くだけで、アクセスの大半をそこで賄える**。キャッシュもメモリインタリーブも仮想記憶（→ [5-1 オペレーティングシステム](../05-software/5-1-オペレーティングシステム.md)）も、この性質の上に成り立っている。

## 2. 半導体メモリの種類

### 2.1 RAM

| | SRAM | DRAM |
| --- | --- | --- |
| 記憶素子 | **フリップフロップ** | コンデンサ（蓄えた電荷） |
| リフレッシュ | **不要** | **必要**（電荷が放電するため定期的に再書込み） |
| 速度 | 速い | 遅い |
| 集積度・単価 | 低い・高い | **メモリセル構成が単純なので高集積・ビット当たりの単価が安い** |
| 主な用途 | **キャッシュメモリ** | **主記憶** |

**SRAMと比較したDRAMの特徴は「メモリセル構成が単純なので、ビット当たりの単価が安くなる」**ことである。SRAMは1ビットに6個程度のトランジスタ（フリップフロップ）を要するが、DRAMはトランジスタ1個とコンデンサ1個で済む。この構造の差が集積度と単価の差になり、そのまま用途を分けている。

誤答として並ぶ「主にキャッシュメモリとして使用される」「リフレッシュが不要」「フリップフロップを用いる」は、いずれも**SRAMの特徴**である。

### 2.2 フラッシュメモリ

電源を切っても内容が保持される不揮発性メモリで、SSDやUSBメモリに使われる。1つのメモリセルに何ビット記録するかで種類が分かれる。

| 種類 | 1セルあたり | 特徴 |
| --- | --- | --- |
| SLC (Single-Level Cell) | 1ビット | 高速・高耐久だが高価 |
| **MLC (Multi-Level Cell)** | **2ビット以上** | 大容量・低価格だが、書換え可能回数と速度で劣る |
| TLC / QLC | 3 / 4ビット | さらに大容量・低価格 |

**MLCフラッシュメモリの特徴は「一つのメモリセルに2ビット以上のデータを記憶する」**ことである。1つのセルに蓄える電荷量を細かく段階分けして、複数ビットを表現する。段階が細かくなるほど判別がシビアになるので、**容量と引き換えに信頼性・速度・寿命を犠牲にする**という関係になる。

誤答との区別も押さえる。「コンデンサに蓄えた電荷を用いる」はDRAM、「電気抵抗の値を用いる」はReRAMなどの新型不揮発性メモリ、「フリップフロップを利用する」はSRAMの説明である。

> **出題** SRAMとDRAM: H25午前I問8 ｜ MLCフラッシュメモリ: H29午前II問22

## 3. キャッシュメモリ

**キャッシュメモリ**は、主記憶の一部の写しを高速なSRAMに保持しておき、CPUからのアクセスをそこで済ませる仕組みである。

### 3.1 平均アクセス時間の計算

**4回出題されている最頻出テーマ**である。

キャッシュのアクセス時間を $x$、主記憶のアクセス時間を $y$、**キャッシュに存在しない確率（ミス率）を $r$** とすると、平均アクセス時間は

$$ (1 - r) \cdot x + r \cdot y $$

となる。ヒット率 $(1-r)$ でキャッシュの時間 $x$、ミス率 $r$ で主記憶の時間 $y$ がかかる、という単純な期待値である。

ここで重要なのは、**容量 $a$、$b$ はこの式に一切現れない**という点である。「容量比で按分する」形の選択肢が必ず用意されるが、アクセス時間を決めるのは**容量の比ではなくヒット率**である。局所性のおかげで、小さなキャッシュでも高いヒット率が得られるからこそキャッシュは成立する。容量比で決まるなら、小さなキャッシュにはほとんど効果がないことになってしまう。

**計算例**：キャッシュメモリのアクセス時間が主記憶のアクセス時間の $1/30$ で、ヒット率が95%のとき、実効メモリアクセス時間は主記憶のアクセス時間の約何倍か。

主記憶のアクセス時間を1とすると、キャッシュは $1/30$。ヒット率0.95、ミス率0.05なので、

$$ 0.95 \times \frac{1}{30} + 0.05 \times 1 = 0.0317 + 0.05 = 0.0817 \approx \mathbf{0.08} $$

ミス率がわずか5%でも、その寄与（0.05）がヒット時の寄与（0.032）を上回っている点に注目してほしい。**ミスのコストが大きいので、ヒット率を数%上げる効果は非常に大きい**。キャッシュの設計がヒット率の向上に注力する理由がここにある。

### 3.2 構成に関する用語

| 用語 | 内容 |
| --- | --- |
| ライン（ブロック） | キャッシュと主記憶の間で転送する単位。空間的局所性を活かすため数十バイト単位でまとめて転送する |
| ダイレクトマップ方式 | 主記憶のアドレスからキャッシュ上の位置が一意に決まる。単純だが競合が起きやすい |
| フルアソシアティブ方式 | どこにでも置ける。競合しないが検索回路が高価 |
| セットアソシアティブ方式 | 両者の折衷。実用上の標準 |
| コヒーレンシ（一貫性） | 複数のキャッシュと主記憶の内容が矛盾しないこと |

> **出題** キャッシュの平均アクセス時間: H22午前I問4、H25午前I問4、H29午前I問4、R1午前I問5（計4回） ｜ 実効メモリアクセス時間: R4午前I問4

## 4. キャッシュの書込み方式

CPUがデータを**書き込む**とき、キャッシュと主記憶をどう同期させるかで2方式がある。**3回出題されている**。

| 方式 | 動作 | 長所 | 短所 |
| --- | --- | --- | --- |
| **ライトスルー方式** | **データをキャッシュメモリと主記憶の両方に同時に書き込む** | **主記憶の内容が常に最新**。一貫性の管理が簡単 | 書込みのたびに主記憶アクセスが発生し遅い |
| **ライトバック方式** | データをキャッシュだけに書き、**追い出されるときに主記憶へ書き戻す** | **プロセッサから主記憶への書込み頻度を減らせる** | 主記憶が古い状態になる。一貫性の管理が複雑 |

**ライトバック方式を使用する目的は「プロセッサから主記憶への書込み頻度を減らす」**ことである。同じ場所に何度書き換えても主記憶へのアクセスは追い出し時の1回で済む。時間的局所性があるほど効果が大きい。

誤答として並ぶ記述を整理する。

| 記述 | 誤りの理由 |
| --- | --- |
| ライトスルー方式では、データをキャッシュメモリだけに書き込むので高速に書込みができる | **ライトバック方式**の説明 |
| ライトバック方式では、両方に同時に書き込むので速度が遅い | **ライトスルー方式**の説明（2つが入れ替わっている） |
| ライトバック方式では、キャッシュミス時に主記憶へ書き戻す必要が生じることはない | **逆**。書き戻しが必要になるのがライトバック方式の性質 |
| ライトバック方式は、キャッシュと主記憶の一貫性を保ちながら書込みを行う | 一貫性を保つのは**ライトスルー方式** |
| ライトバック方式は、マルチプロセッサでキャッシュ管理をライトスルーより簡単な回路で実現する | **逆**。ライトバックのほうが一貫性制御が複雑になる |

**「同時に書く＝ライトスルー＝常に最新＝遅い」「後で書く＝ライトバック＝速い＝一貫性が複雑」**という2本の軸で覚えると、入れ替えの引っかけを見抜ける。

> **出題** ライトスルーとライトバック: H24午前I問5、R3午前I問4、R7午前II問22 ｜ ライトバックの目的: H26午前I問4

## 5. メモリインタリーブ

**メモリインタリーブ**は、**主記憶を複数のバンク（区画）に分け、連続したアドレスを各バンクに振り分けて配置することで、並列的にアクセスして高速化する**技術である。**4回出題されている**。

```
バンク0: アドレス 0, 4,  8, 12, ...
バンク1: アドレス 1, 5,  9, 13, ...
バンク2: アドレス 2, 6, 10, 14, ...
バンク3: アドレス 3, 7, 11, 15, ...
```

連続したアドレス 0, 1, 2, 3 を読むとき、4つのバンクに同時にアクセスを開始できる。DRAMは1回のアクセス後に次のアクセスを受け付けられるまで待ち時間（プリチャージ）があるが、別のバンクなら待たずに始められる。

有効なのは**連続したアドレスへのアクセス**のときである。空間的局所性により、命令の読み出しや配列の走査はまさに連続アクセスになるので、実用上よく効く。逆に**同一バンク内に連続してアクセスしても効果はない**。並列に動かす相手がいないからである。

したがって正しい説明は、**「複数のバンクに割り振った連続したアドレスにアクセスしたとき、アクセス時間を短くする」**となる。

誤答として並ぶ他技術との区別が、そのまま記憶装置周辺の用語整理になる。

| 記述 | 実際は何の説明か |
| --- | --- |
| 主記憶と外部記憶を一元的にアドレス付けし、物理容量を超えるメモリ空間を提供する | **仮想記憶**（→ [5-1](../05-software/5-1-オペレーティングシステム.md)） |
| 主記憶と磁気ディスク装置との間にバッファメモリを置いて、双方のアクセス速度の差を補う | **ディスクキャッシュ** |
| 主記憶と入出力装置との間でCPUを介さずにデータ転送を行う | **DMA** |
| 新しい情報をキャッシュに取り出すとき、不要になった情報を主記憶に書き込む | **ライトバック** |
| 主記憶の更新と同時にキャッシュメモリの更新を行う | **ライトスルー** |
| 一つのバンクが故障してもシステムが停止しないようにする | 冗長化（インタリーブの目的ではない） |

**「バンクに分けて並列アクセス」という語が出てきたらメモリインタリーブ**と判断できる。

> **出題** メモリインタリーブ: H23午前I問4、H26午前II問22、H28午前I問4、R5午前II問22（計4回）

## 6. メモリの誤り制御

主記憶は宇宙線などの影響でビットが反転することがある（ソフトエラー）。サーバ用途ではこれを検出・訂正する**ECCメモリ**を使う。

**2ビットの誤りを検出し、1ビットの誤りを訂正するために用いるのは「ハミング符号」**である。

誤答として並ぶ符号との能力の差を押さえる。

| 符号 | できること |
| --- | --- |
| 偶数パリティ・垂直パリティ | 1ビットの誤り**検出**のみ。訂正はできない |
| チェックサム | 誤り**検出**。訂正はできない |
| **ハミング符号** | **1ビットの誤り訂正＋2ビットの誤り検出** |

**訂正までできるのはハミング符号だけ**である。パリティは「どこかが違う」ことしかわからないが、ハミング符号は複数のパリティビットを重ね合わせることで**誤ったビットの位置まで特定できる**ため訂正できる。符号そのものの原理と計算は [1-3 情報に関する理論](../01-basic-theory/1-3-情報に関する理論.md)、通信路での誤り制御への応用は [10-2 データ通信と制御](../10-network/10-2-データ通信と制御.md) で扱う。

> **出題** ECCメモリとハミング符号: H23午前II問22

## この章のまとめ

- 記憶階層が成立するのは**局所性**があるから。キャッシュもインタリーブも仮想記憶もこの性質に依存している。
- **DRAMはセル構成が単純で安価・高集積、SRAMはフリップフロップで高速**。用途は主記憶とキャッシュに分かれる。**MLCは1セルに2ビット以上**。
- キャッシュの平均アクセス時間は **$(1-r)x + ry$**。**容量は式に現れない**。ヒット率がすべてを決める。
- **ライトスルーは同時に書いて主記憶が常に最新、ライトバックは後で書いて主記憶への書込み頻度を減らす**。2方式の説明を入れ替えた選択肢が定番。
- **メモリインタリーブは複数バンクへ連続アドレスを振り分けて並列アクセスする**。仮想記憶・ディスクキャッシュ・DMAとは別物。
- **ECCメモリでの1ビット訂正・2ビット検出はハミング符号**。パリティやチェックサムは検出しかできない。
