# 3-3 バス

コンピュータ内部で、プロセッサ・メモリ・入出力装置の間をつなぐ伝送路が**バス**である。

ネットワークのケーブルが装置と装置をつなぐのに対し、バスは**1台のコンピュータの中**で同じ役割を果たす。だから考えるべきことも似ている。何本の線を使うか（パラレルかシリアルか）、どれだけの速さで送れるか、複数の相手がつながったとき誰が送るかをどう決めるか──ネットワークで見た論点が、より小さなスケールで再現されている。

午前IIの問22前後から出題されるが、16年で1問と出題は少ない。周辺機器を接続するインタフェースは [3-4 入出力デバイス](3-4-入出力デバイス.md) で扱う。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、理解に必要な基礎を補っている。

## 1. バスの分類

バスは、運ぶ信号の種類と接続する範囲で分類される。

| 分類 | 内容 |
| --- | --- |
| アドレスバス | アクセス先のアドレスを伝える。線の本数がアドレス空間の広さを決める |
| データバス | データそのものを伝える |
| 制御バス | 読み書きの区別やタイミングなどの制御信号を伝える |

接続する範囲では、プロセッサとメモリを結ぶ**システムバス（内部バス）**と、周辺機器を接続する**入出力バス（拡張バス）**に分かれる。CPUに近いほど高速・短距離、周辺に行くほど低速・長距離という構成になる。

## 2. パラレル伝送とシリアル伝送

| 方式 | 仕組み | 代表 |
| --- | --- | --- |
| パラレル伝送 | 複数の線で同時に複数ビットを送る | 旧PCI、IDE（パラレルATA）、SCSI |
| **シリアル伝送** | 1本（1対）の線で1ビットずつ順に送る | **PCI Express**、シリアルATA、USB |

直感的にはパラレルのほうが速そうだが、**現在の高速インタフェースはほとんどシリアルに移行している**。理由は2つある。

- **スキュー**：パラレルでは複数の線を同時に出発した信号が、線の長さや特性のわずかな差で到着時刻にずれを生じる。速度を上げるほど1ビットの時間が短くなるので、このずれが許容できなくなる。
- **漏話**：線を密に並べるほど相互に干渉する。これはツイストペアケーブルで見た問題と同じである（→ [10-1 ネットワーク方式](../10-network/10-1-ネットワーク方式.md)）。

1本の線を極限まで高速化し、足りなければ**独立した伝送路（レーン）を複数束ねる**ほうが、結果的に速く安定する。この「1本を速く、必要なら束ねる」という設計思想は、ネットワークにおけるリンクアグリゲーションと同じ発想である。

## 3. PCI Express

**PCI Express（PCIe）**は、現在のPCにおける標準的な拡張バスである。シリアル伝送を採用し、**レーン**と呼ばれる伝送路の単位を複数束ねて帯域を確保する（×1、×4、×8、×16）。

| 世代 | 1レーンの片方向転送レート（概算） | 符号化方式 |
| --- | --- | --- |
| PCI Express 2.0 | 500 Mバイト/秒 | 8b/10b |
| PCI Express 3.0 | 約 1 Gバイト/秒 | **128b/130b** |
| PCI Express 4.0 | 約 2 Gバイト/秒 | 128b/130b |
| PCI Express 5.0 | 約 4 Gバイト/秒 | 128b/130b |

出題されたのは世代間の比較である。正しいのは、

> **1レーンの片方向最大転送レートは、PCI Express 4.0 は PCI Express 3.0 の2倍、PCI Express 5.0 は PCI Express 4.0 の2倍である。**

**世代が上がるごとに転送レートが倍になる**という、わかりやすい進化の仕方をしている。

誤答との区別も押さえる。

| 記述 | 正しくは |
| --- | --- |
| PCI Express 4.0 はそれ以前のものと後方互換性がない | **後方互換性はある**。世代をまたいで接続でき、低いほうの世代で動作する |
| いずれも規格上の最大レーン数は32レーンである | **最大16レーン**（×16）である |
| いずれもシリアル転送において 8b/10b 変換を採用している | **8b/10b は2.0まで**。3.0以降は**128b/130b**を採用している |

**8b/10b** は、8ビットのデータを10ビットの符号に変換して送る方式である。0と1の出現を均衡させてクロックを復元しやすくする狙いがあるが、**20%がオーバヘッド**になる。3.0以降の**128b/130b**は、同じ目的をわずか約1.5%のオーバヘッドで達成する。3.0が2.0の2倍の実効速度を得られたのは、生の伝送レートの向上に加えてこの符号化効率の改善が効いている。

> **出題** PCI Express の世代比較: R6午前II問22

## 4. バスの性能

バスの転送速度は次の式で決まる。

$$ \text{転送速度（バイト/秒）} = \text{バス幅（バイト）} \times \text{バスクロック周波数（Hz）} $$

パラレルバスではバス幅を広げることで速度を上げたが、前述のスキューと漏話の問題で頭打ちになった。シリアルバスではクロック周波数を上げ、レーン数で掛け算する形に変わっている。

複数の装置が1本のバスを共有する場合、**誰が使うかを決める調停（バスアービトレーション）**が必要になる。これはネットワークのメディアアクセス制御（→ [10-2 データ通信と制御](../10-network/10-2-データ通信と制御.md)）と同じ問題であり、集中調停方式と分散調停方式という解法の分かれ方もよく似ている。PCI Expressがスイッチを介した**ポイントツーポイント接続**を採るのは、共有バスの調停問題そのものを回避するためである。ネットワークがバス型イーサネットからスイッチングへ移行したのと、まったく同じ流れが起きている。

---

## この章のまとめ

- 高速インタフェースが**シリアル伝送に移行した**のは、パラレルの**スキューと漏話**が速度向上の壁になったため。1本を速くして**レーンで束ねる**のが現在の方式。
- **PCI Expressは世代ごとに1レーンの転送レートが2倍**になる。**後方互換性はあり、最大16レーン**、**3.0以降の符号化は128b/130b**。
- バスの調停も、ポイントツーポイント化による回避も、ネットワークのメディアアクセス制御と同じ構造の問題である。
