# 3-5 入出力装置

ディスプレイ、プリンタ、補助記憶装置といった**実際に人やデータと接する装置**を扱う。

午前IIの問22前後から出題されるが、16年で1問と出題は少ない。出題されたのは**ビデオメモリ容量の計算**で、これは「解像度×色深度＝必要な記憶容量」という単純な掛け算に帰着する。同じ考え方が画像や音声のデータ量計算（→ [8-1 マルチメディア技術](../08-information-media/8-1-マルチメディア技術.md)）にも使えるので、計算の型として押さえておく価値がある。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、装置の分類を簡潔に補っている。

## 1. 表示装置とビデオメモリ

### 1.1 ビデオメモリ容量の計算

ディスプレイに表示する画面の内容は、**ビデオメモリ（VRAM）**に1画素ずつ保持される。したがって必要な容量は

$$ \text{ビデオメモリ容量} = (\text{横の画素数}) \times (\text{縦の画素数}) \times (1画素あたりのビット数) $$

で求まる。1画素あたりのビット数（色深度）は、**表現できる色数の2を底とする対数**である。

| 色数 | 1画素あたり |
| --- | --- |
| 256色 ($2^8$) | 8ビット = 1バイト |
| 65,536色 ($2^{16}$) | **16ビット = 2バイト** |
| 約1,677万色 ($2^{24}$、フルカラー) | 24ビット = 3バイト |

**計算例**：表示解像度が $1{,}000 \times 800$ ドットで、65,536色（$2^{16}$ 色）を表示するのに最低限必要なビデオメモリ容量は何Mバイトか。ここで、1Mバイト＝1,000kバイト、1kバイト＝1,000バイトとする。

画素数は $1{,}000 \times 800 = 800{,}000$ 画素。$2^{16}$ 色は16ビット＝2バイトなので、

$$ 800{,}000 \times 2 = 1{,}600{,}000\ \text{バイト} = \mathbf{1.6\ M\text{バイト}} $$

注意点が2つある。

- **色数からビット数への変換を忘れない**。「65,536色」をそのまま掛けてはいけない。$2^{16}$ と書かれていれば指数の16がそのままビット数である。
- **単位の定義を問題文どおりに使う**。この問題では $1\text{M} = 10^6$ と指定されているが、$1\text{M} = 2^{20} = 1{,}048{,}576$ と定義される場合もある。問題文の但し書きを必ず確認する。

### 1.2 表示装置に関する用語

| 用語 | 内容 |
| --- | --- |
| 解像度 | 画面を構成する画素数。$1{,}920 \times 1{,}080$ など |
| 色深度（ビット深度） | 1画素に割り当てるビット数。色数を決める |
| リフレッシュレート | 1秒間に画面を描き換える回数（Hz） |
| 液晶ディスプレイ (LCD) | バックライトと液晶で表示する。現在の主流 |
| 有機ELディスプレイ | 素子自体が発光する。バックライト不要で薄く、黒が締まる |

> **出題** ビデオメモリ容量: H22午前II問22

## 2. その他の入出力装置

### 2.1 入力装置

| 装置 | 特徴 |
| --- | --- |
| キーボード、マウス、タッチパネル | 人が直接操作する |
| イメージスキャナ | 紙の画像を読み取る。解像度はdpiで表す |
| OCR / OMR | 文字認識 / マーク読取り。試験の答案用紙はOMRで読み取る |
| バーコードリーダ、RFIDリーダ | 商品や物品を識別する（→ [6-1 ハードウェア](../06-hardware/6-1-ハードウェア.md)） |
| 各種センサ | 温度・加速度・照度などを電気信号に変換する |

### 2.2 出力装置

| 装置 | 特徴 |
| --- | --- |
| レーザプリンタ | 静電気とトナーで印字する。高速・高品質。ページ単位で処理する |
| インクジェットプリンタ | インクを吹き付ける。安価でカラー印刷に強い |
| 3Dプリンタ | 樹脂などを積層して立体物を造形する |

### 2.3 補助記憶装置

| 装置 | 特徴 |
| --- | --- |
| 磁気ディスク装置（HDD） | 円盤の磁性体に記録する。大容量・安価だが機械動作のため遅い |
| SSD | フラッシュメモリを使う（→ [3-2 メモリ](3-2-メモリ.md)）。高速で静音・耐衝撃だが書換え回数に上限がある |
| 光ディスク（CD / DVD / BD） | レーザで読み書きする。配布・長期保存向け |
| 磁気テープ | 順次アクセス専用。容量単価が最も安くバックアップに使われる（→ [15-4 サービスの運用](../15-service-management/15-4-サービスの運用.md)） |

補助記憶装置を複数台組み合わせて信頼性や性能を高める**RAID**、ネットワーク経由で共有する**NAS / SAN** は、システム構成の話として [4-1 システムの構成](../04-system-components/4-1-システムの構成.md) で扱う。

## この章のまとめ

- **ビデオメモリ容量 = 横画素数 × 縦画素数 × 1画素あたりのバイト数**。色数は $2^n$ の形から**ビット数 $n$** を読み取る。単位の定義は問題文の指定に従う。
- 補助記憶は**HDD（大容量・安価）、SSD（高速・耐衝撃）、磁気テープ（容量単価が最安・バックアップ向け）**と用途で使い分ける。
