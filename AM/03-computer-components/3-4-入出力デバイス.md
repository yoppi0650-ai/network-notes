# 3-4 入出力デバイス

コンピュータ本体と周辺機器をつなぐ**インタフェース**を扱う。

[3-3 バス](3-3-バス.md) がコンピュータ内部の伝送路だったのに対し、ここで扱うのは**外部の機器を接続する規格**である。規格ごとに「何をつなぐために作られたか」が違い、そこから速度・コネクタ形状・給電能力といった仕様が決まっている。設問も**「この規格は何をつなぐためのものか」**を問う形で出る。

午前IIの問22前後から出題されるが、16年で1問と出題は少ない。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、主要なインタフェースの整理を補っている。

## 1. 周辺機器インタフェースの一覧

**「何と何を結ぶためのものか」**で整理すると、設問にそのまま対応できる。

| 規格 | 結ぶもの | 代表的な接続先 |
| --- | --- | --- |
| **USB** | PCと**多様な周辺機器** | キーボード、マウス、スピーカ、プリンタ、光学ドライブ、USBメモリ |
| **シリアルATA (SATA)** | PCと**高速な記憶装置** | 磁気ディスク装置、SSD、DVDドライブ |
| **HDMI** | PCと**ディジタルAV機器** | ディスプレイ、セットトップボックス、DVDプレーヤー |
| **IEEE 1394** | PCとAV機器 | ディジタルビデオカメラ |
| RS-232C | PCと**通信機器** | ルータ、モデム（コンソール接続） |
| Bluetooth | PCと近距離の無線機器 | ワイヤレスマウス、ヘッドセット（→ [10-5](../10-network/10-5-ネットワーク応用.md)） |
| NVMe | PCとSSD | PCI Express経由で接続する高速SSD（→ [3-3](3-3-バス.md)） |

USBだけが**汎用**で、ほかは**用途に特化**している点が特徴である。USBは「とにかく何でもつながる」ことを優先した結果、電力供給やホットプラグに対応し、速度よりも汎用性に重きを置いた設計になった。一方SATAやHDMIは、接続先が決まっているぶん、その用途に最適化した仕様を持てる。

## 2. シリアルATA

**シリアルATA（SATA）**の説明として出題されたのは、

> **PCと周辺機器とを結ぶシリアルインタフェースであり、磁気ディスク装置、DVDドライブなどの高速な周辺機器を接続する。**

である。誤答は上表の他の規格の説明に置き換えられている。

- 「キーボード、マウス、スピーカ、プリンタ、CD-RWドライブなど**多岐にわたる**周辺機器を接続する」→ **USB**
- 「PCと**通信機器**とを結び、ルータ又はモデムを接続する」→ **RS-232C**
- 「PCと**ディジタルAV機器**とを結び、セットトップボックス、DVDプレーヤーなどを接続する」→ **HDMI**（またはIEEE 1394）

**「高速な記憶装置」ならSATA、「多岐にわたる周辺機器」ならUSB**という対応で判別できる。

SATAは、それ以前のパラレルATA（IDE）を置き換えたものである。パラレルからシリアルへの移行が起きた理由は [3-3](3-3-バス.md) で述べたスキューと漏話の問題そのもので、ケーブルも太いフラットケーブルから細い7芯ケーブルへと変わり、取り回しと筐体内の空気の流れまで改善された。

> **出題** シリアルATA: H21午前II問22

## 3. 入出力制御の方式

周辺機器とのデータ転送を、CPUがどこまで関与して行うかで方式が分かれる。

| 方式 | 内容 |
| --- | --- |
| プログラム制御方式（直接制御） | CPUが1バイトずつ転送を指示する。CPUが転送中ずっと占有される |
| **DMA制御方式** | **DMAコントローラが、CPUを介さずに主記憶と入出力装置の間でデータ転送を行う**。CPUは転送の開始と完了通知だけに関わる |
| チャネル制御方式 | 専用の入出力プロセッサ（チャネル）が転送を制御する。汎用大型機で使われた |

**DMA（Direct Memory Access）**の価値は、**CPUを転送作業から解放する**点にある。ディスクから1 Mバイト読み込むあいだ、CPUが1バイトずつ面倒を見ていては他の仕事ができない。DMAコントローラに任せておけば、CPUは別の処理を進められ、転送完了時に割込みで知らされる（→ [3-1 プロセッサ](3-1-プロセッサ.md)）。

なお、DMAはメモリインタリーブやディスクキャッシュと誤答選択肢の中で混同されやすい（→ [3-2 メモリ](3-2-メモリ.md)）。**「CPUを介さずに主記憶と入出力装置の間で転送する」のがDMA**である。

---

## この章のまとめ

- インタフェースは**「何と何を結ぶか」**で覚える。**USBは汎用、SATAは高速な記憶装置、HDMIはディジタルAV機器、RS-232Cは通信機器**。
- **シリアルATAは磁気ディスク装置やDVDドライブなどの高速な周辺機器を接続する**シリアルインタフェース。
- 入出力制御では、**DMAがCPUを介さずに主記憶と入出力装置の間でデータを転送する**。
