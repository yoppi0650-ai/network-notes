# 20-1 技術開発戦略の立案

**技術をどう育て、どう事業につなげるか**を決める領域を扱う。

技術開発が独自の戦略領域になるのは、**技術の価値が実現するまでに時間がかかり、しかも不確実**だからである。研究に投じた資金が製品になるまで何年もかかり、途中で別の技術に追い越されることもある。この不確実性のもとで判断するために、技術の進歩のパターン（Sカーブ）、未来の予測手法（デルファイ法）、自社の中核とすべき技術の見極め（コア技術）といった枠組みが用意されている。

午前Iの問26・問27前後から出題される。16年で10問。**デルファイ法は4回**出題されている頻出テーマである。

## 1. 技術のSカーブ

> **「技術のSカーブ」**の説明として適切なものはどれか。

答えは、

> **技術の進歩の過程を表すものであり、当初は緩やかに進歩するが、やがて急激に進歩し、成熟期を迎えると進歩は停滞気味になる。**

```
技術の進歩度
  │                    ＿＿＿＿＿＿ ← 成熟期（停滞）
  │              ／
  │        ／              ← 急激に進歩
  │ ＿＿／
  │／                      ← 当初は緩やか
  └──────────────────────→ 時間・投資量
```

> 技術は、理想とする技術を目指す過程において、**導入期、成長期、成熟期、衰退期、そして次の技術フェーズに移行する**という進化の過程をたどる。この技術進化過程を表すものはどれか。

答えも **技術のSカーブ**である。

### 1.1 S字になる理由

3つの段階には、それぞれ理由がある。

| 段階 | なぜそうなるか |
| --- | --- |
| **当初は緩やか** | 基礎的な理解が不足し、試行錯誤が多い。投資しても成果が出にくい |
| **急激に進歩** | 原理が確立し、改良の方向が見える。投資が成果に直結する |
| **成熟期に停滞** | **物理的・理論的な限界に近づく**。投資を増やしても改善幅が小さくなる |

**成熟期の停滞が、次の技術への移行を促す**。既存技術に投資を続けても得るものが少なくなるので、新しいSカーブの立ち上がりへ乗り換える判断が必要になる。このとき、**既存技術で成功している企業ほど乗り換えが遅れる**という問題がよく知られている。いま儲かっている技術を捨てる判断は難しいためである。

### 1.2 似たS字曲線との区別

誤答には**形の似た別の曲線**が並ぶ。何を測っているかで判別する。

| 記述 | 実際は何か |
| --- | --- |
| **技術の進歩の過程**。当初緩やか、やがて急激、成熟期に停滞 | **技術のSカーブ** |
| 技術の**期待感の推移**。黎明期、流行期、反動期、回復期、安定期に分類される | **ハイプサイクル** |
| **生産量と生産性**の関係。生産量の累積数が増加するほど生産性が向上する | **ラーニングカーブ（経験曲線）** |
| **故障発生の傾向**。初期故障期間と摩耗故障期間で故障率が高く、偶発故障期間で低い | **バスタブ曲線**（→ [4-2 システムの評価指標](../04-system-components/4-2-システムの評価指標.md)） |
| 商品の売上が導入期・成長期・成熟期・衰退期と推移する | **プロダクトライフサイクル**（→ [19-2 マーケティング](../19-business-strategy-management/19-2-マーケティング.md)） |
| 価格と需要量の関係 | 需要曲線 |

**「技術の進歩」ならSカーブ、「技術への期待」ならハイプサイクル、「売上」ならプロダクトライフサイクル、「故障率」ならバスタブ曲線**と、縦軸が何かで区別する。

**ハイプサイクル**は特に紛らわしい。こちらは**過度な期待が一度崩れてから実用化に向かう**という形（最初に大きな山があり、落ち込んでから緩やかに回復する）で、単調なS字ではない。

> **出題** 技術のSカーブ: H23午前I問27 ｜ 技術進化過程: H24午前I問27

## 2. イノベーションの類型

イノベーションは**何を変えるか**と**変化の大きさ**で分類される。

### 2.1 対象による分類

| 類型 | 内容 |
| --- | --- |
| **プロダクトイノベーション** | **製品そのものの革新**。新しい製品を生み出す |
| **プロセスイノベーション** | **作り方の革新**。製造工程や業務プロセスを改善する |

> **プロダクトイノベーションの例**として適切なものはどれか。

答えは **マルチコアCPUを採用した、高性能で低消費電力の製品を開発する**である。**新しい製品を生み出している**のでプロダクトイノベーションにあたる。

誤答はいずれも**プロセスイノベーション**である。

| 記述 | 類型 |
| --- | --- |
| シックスシグマの工程管理を導入し、製品品質を向上する | プロセス |
| ジャストインタイム方式を採用し、部品在庫を減らす | プロセス（→ [21-2 エンジニアリングシステム](../21-business-and-industry/21-2-エンジニアリングシステム.md)） |
| 製造方法を見直し、コストを下げた製品を製造する | プロセス |
| **マルチコアCPUを採用した高性能で低消費電力の製品を開発する** | **プロダクト** |

**「製品を開発する」ならプロダクト、「作り方を変える」ならプロセス**と判別できる。「コストを下げた製品を製造する」は製品が変わったように見えるが、**変えたのは製造方法**なのでプロセスイノベーションである。

### 2.2 変化の大きさによる分類

| 類型 | 内容 |
| --- | --- |
| **ラディカルイノベーション（急進的革新）** | **経営構造の全面的な変革を必要とする技術革新** |
| **インクリメンタルイノベーション（漸進的革新）** | **既存製品の細かな部分改良を積み重ねる技術革新** |

> **ラディカルイノベーション**の説明として適切なものはどれか。

答えは **経営構造の全面的な変革を必要とする技術革新**である。

**「経営構造の全面的な変革を必要とする」**という点が核心である。ラディカルイノベーションは技術が新しいだけでなく、**それを扱うために組織や事業の仕組みごと作り直さなければならない**。だから既存企業にとって難しく、しばしば新興企業が担い手になる。

誤答との区別を押さえる。

| 記述 | 類型 |
| --- | --- |
| 革新的な新製品を開発するといった、製品そのものに関する技術革新 | **プロダクトイノベーション** |
| 既存製品の細かな部分改良を積み重ねる技術革新 | **インクリメンタルイノベーション** |
| **経営構造の全面的な変革を必要とする技術革新** | **ラディカルイノベーション** |
| 研究開発過程、製造工程、及び物流過程の技術革新 | **プロセスイノベーション** |

### 2.3 その他の関連概念

| 用語 | 内容 |
| --- | --- |
| **破壊的イノベーション** | 当初は性能が劣るが、別の価値基準で既存市場を侵食する |
| **オープンイノベーション** | 社外の技術や知見を取り込んで革新を起こす |
| **死の谷** | 研究と事業化の間にある資金・体制の断絶 |
| **ダーウィンの海** | 事業化と market での成功の間にある競争の壁 |
| **キャズム** | 初期採用者と主流市場の間にある普及の溝 |

**「死の谷」「ダーウィンの海」「キャズム」は、技術が事業として成立するまでに越える壁**を、段階別に名付けたものである。技術として優れていても、それだけでは事業にならないという認識が、これらの用語の背景にある。

> **出題** ラディカルイノベーション: H21午前I問27 ｜ プロダクトイノベーション: H25午前I問27

## 3. コア技術

> **コア技術の事例**として適切なものはどれか。

答えは **競合他社がまねできないような、自動車エンジンのアイドリングストップ技術**である。

**コア技術の条件は「他社がまねできない」**ことである。[19-1 経営戦略手法](../19-business-strategy-management/19-1-経営戦略手法.md) のベンチマーキングの誤答に現れた**コアコンピタンス**（他社にはまねのできない企業独自のノウハウや技術などの強み）と同じ発想である。

誤答として並ぶ記述を確認する。

| 記述 | なぜコア技術でないか |
| --- | --- |
| アライアンスを組んでインタフェースなどを策定し、**共通で使うことを目的とした**技術 | **共通化を目的とするので差別化にならない** |
| **競合他社がまねできない**ような自動車エンジンのアイドリングストップ技術 | **コア技術** |
| 競合他社と**同じ**CPUコアを採用し、ソフトウェアの移植性を生かす技術 | 同じものを使っているので差別化にならない |
| 早期開発・早期市場投入を目的として、**汎用部品を組み合わせて**開発する技術 | 汎用品の組合せは模倣しやすい |

3つの誤答に共通するのは、**他社と同じものを使う／共通化する**という性質である。これらは効率やスピードには寄与するが、**競争優位の源泉にはならない**。

コア技術を特定する意味は、**資源配分の判断**にある。すべての技術を自社で開発するのは不可能なので、**コア技術には集中投資し、それ以外は外部調達や標準品で済ませる**。何を標準に委ねられるかは標準化の進み方に左右されるため、デジュール標準・デファクトスタンダード・フォーラム標準の違い（→ [23-4 その他の法律・ガイドライン・技術者倫理](../23-legal-affairs/23-4-その他の法律-ガイドライン-技術者倫理.md)）も戦略判断の前提になる。この判断が [14-10 プロジェクトの調達](../14-project-management/14-10-プロジェクトの調達.md) の内外製分析や、[19-1 経営戦略手法](../19-business-strategy-management/19-1-経営戦略手法.md) のファブレス・ファウンドリの分業につながる。

> **出題** コア技術: H26午前I問27

## 4. 技術予測の手法

技術開発戦略では、**まだ存在しないものについて判断する**必要がある。そのための予測手法がいくつかある。

### 4.1 デルファイ法

**4回出題されている**最頻出テーマである。

> 現在の動向から未来を予測したり、システム分析に使用したりする手法であり、**専門的知識や経験を有する複数の人にアンケート調査を行い、その結果を互いに参照した上で調査を繰り返して、集団としての意見を収束させる**手法はどれか。

答えは **デルファイ法**である。別の設問では、

> **専門家にアンケートを何度か繰り返し、その結果をフィードバックして意見を収束させる。**

と表現されている。

**手順の要点**は次の3つである。

| 要素 | 内容 |
| --- | --- |
| **専門家が対象** | 一般の人ではなく、知識と経験をもつ者に聞く |
| **アンケート形式（匿名）** | 対面の議論ではない |
| **繰り返しとフィードバック** | 結果を全員に示し、それを見たうえで再度回答させる |

**なぜ対面の会議ではなくアンケートを繰り返すのか**。対面の議論では、声の大きい人や地位の高い人の意見に引きずられる。匿名のアンケートならその影響を避けられる。一方、1回で終われば単なる意見の寄せ集めになるので、**他の専門家の見解を見たうえで考え直す機会**を設ける。これを繰り返すと意見が収束していく。

**集団の知見を、集団力学の弊害なしに引き出す**ための工夫だといえる。

誤答として並ぶ手法との区別を押さえる。

| 記述 | 手法 |
| --- | --- |
| 会議の参加者に自由にアイデアを出させ、批判や評価を加えない | **ブレーンストーミング** |
| 将来の意思決定の各段階を樹木構造で示した図に基づいて、最適な経路を求める | **デシジョンツリー**（→ [14-8 プロジェクトのリスク](../14-project-management/14-8-プロジェクトのリスク.md)） |
| **専門家にアンケートを繰り返し、結果をフィードバックして意見を収束させる** | **デルファイ法** |
| 予測項目間の影響を定量化してマトリックスで示し、波及効果をシミュレーションする | **クロスインパクト法** |
| 因果関係分析法、クロスセクション法、時系列回帰分析法 | いずれもデータに基づく統計的予測手法 |

**「専門家」「アンケート」「繰り返し」「収束」**の4語がそろえばデルファイ法である。

### 4.2 その他の予測・発想手法

| 手法 | 内容 |
| --- | --- |
| **ブレーンストーミング** | 自由にアイデアを出し、**批判・評価を加えない**。質より量を重視する |
| シナリオライティング | 複数の未来のシナリオを描き、それぞれへの対応を検討する |
| クロスインパクト法 | 予測項目間の相互影響を定量化する |
| **ロードマップ** | 技術と製品の開発計画を時間軸に沿って図示する |

**技術ロードマップ**は、「いつまでにどの技術を獲得し、どの製品に載せるか」を時系列で示したものである。[1. 技術のSカーブ](#1-技術のsカーブ) で見たとおり技術の進歩には時間がかかるので、**製品化の時期から逆算して、いつ研究を始めるべきかを決める**必要がある。ロードマップはそのための道具になる。

> **出題** デルファイ法: H21午前I問26、H23午前I問26、H25午前I問25、H27午前I問27、H29午前I問29

## この章のまとめ

- **技術のSカーブは「技術の進歩度」の推移**。成熟期の停滞が次の技術への移行を促すが、既存技術で成功している企業ほど乗り換えが遅れる。
- 似たS字曲線は縦軸で区別する。**進歩＝Sカーブ、期待＝ハイプサイクル、売上＝プロダクトライフサイクル、故障率＝バスタブ曲線、生産性＝ラーニングカーブ**。
- イノベーションは**プロダクト（製品）とプロセス（作り方）**、**ラディカル（経営構造の全面的変革を伴う）とインクリメンタル（部分改良の積み重ね）**で分類する。
- **コア技術の条件は「他社がまねできない」**こと。共通化や汎用品の組合せは差別化にならない。
- **デルファイ法は「専門家にアンケートを繰り返し、結果をフィードバックして収束させる」**。対面の議論における集団力学の弊害を避けるための工夫である。
