# 21-2 エンジニアリングシステム

**ものづくりを支える情報システム**を扱う。生産管理、生産方式、製品開発の手法が主な題材である。

この分野を貫く課題は、**多様な要求に、無駄なく、速く応える**ことである。大量生産は効率がよいが多様性に弱い。多品種少量生産は多様性に応えられるが非効率になりやすい。かんばん方式もセル生産方式もコンカレントエンジニアリングも、この相反する要求を両立させるための工夫として生まれた。

午前Iの問28前後から出題される。16年で7問。

## 1. 生産管理の手法

| 手法 | 内容 |
| --- | --- |
| **MRP**（資材所要量計画） | **製品の生産計画に基づいて、その生産に必要な資材の所要量を展開し、これを基準にして資材の需要とその発注時期を算出する** |
| **PLM**（製品ライフサイクル管理） | **製品開発、製造、販売、保守、リサイクルに至る製造業のプロセスにおいて、製品に関連する情報を一元管理し、商品力向上やコスト低減を図る** |
| **FMS**（フレキシブル生産システム） | **NC工作機械、自動搬送装置、倉庫などを有機的に結合し、コンピュータで集中管理することで、多品種少量生産に対応できる生産の自動化を実現する** |
| CAD / CAM / CAE | 設計・製造・解析をコンピュータで支援する |

### 1.1 PLMとその周辺の区別

> **PLM（Product Lifecycle Management）の目的**はどれか。

答えは **製品開発、製造、販売、保守、リサイクルに至る製造業のプロセスにおいて、製品に関連する情報を一元管理し、商品力向上やコスト低減を図る**である。

**PLMの範囲は「開発からリサイクルまで」**と、製品の一生を通した情報管理である。誤答として並ぶ3つは、それぞれ範囲が限定されている。

| 記述 | 実際は何か |
| --- | --- |
| NC工作機械、自動搬送装置、倉庫などを結合し、多品種少量生産に対応する自動化 | **FMS** |
| **製品に関連する情報を一元管理し、商品力向上やコスト低減を図る** | **PLM** |
| 生産計画に基づいて資材の所要量を展開し、需要と発注時期を算出する | **MRP** |
| 部品の供給から製品の販売までの情報をリアルタイムで交換し、在庫削減とリードタイム短縮を実現する | **SCM**（→ [19-4 経営管理システム](../19-business-strategy-management/19-4-経営管理システム.md)） |

**PLMとSCMは紛らわしい**。PLMは**製品の情報**（設計図、部品構成、変更履歴）を管理し、SCMは**モノの流れ**（調達、生産、物流）を管理する。扱うのが情報か物流かで区別できる。

### 1.2 MRPの計算

**2回出題されている**計算問題である。

> ある期間の生産計画において、図の部品表で表される**製品Aの需要量が10個**であるとき、**部品Dの正味所要量**は何個か。ここで、**ユニットBの在庫残が5個、部品Dの在庫残が25個**あり、他の在庫残などはないものとする。
>
> | レベル0 | | レベル1 | | レベル2 | |
> | --- | --- | --- | --- | --- | --- |
> | 製品A | 1 | ユニットB | 4 | 部品D | 3 |
> | | | | | 部品E | 1 |
> | | | ユニットC | 1 | 部品D | 1 |
> | | | | | 部品F | 2 |

**上位レベルから順に、「必要量 − 在庫 ＝ 正味所要量」を計算して下へ展開する**のが手順である。

**① レベル1（ユニット）の正味所要量**

| 品目 | 総所要量 | 在庫 | 正味所要量 |
| --- | --- | --- | --- |
| ユニットB | $10 \times 4 = 40$ 個 | 5個 | **35個** |
| ユニットC | $10 \times 1 = 10$ 個 | 0個 | **10個** |

**② レベル2（部品D）の総所要量**

部品Dは**ユニットBとユニットCの両方に使われる**ので、両方から積み上げる。ここで掛けるのは**正味所要量**であって総所要量ではない。在庫のあるユニットBは35個しか作らないからである。

$$ 35 \times 3 + 10 \times 1 = 105 + 10 = 115\ \text{個} $$

**③ 部品Dの正味所要量**

$$ 115 - 25 = \mathbf{90\ \text{個}} $$

**つまずきやすい点**は2つある。

- **部品Dが複数のユニットに使われている**ことを見落とす。部品表のすべての経路をたどる。
- **在庫を引いた正味所要量を下位に展開する**。総所要量（40個）で計算すると $40 \times 3 + 10 = 130$、$130 - 25 = 105$ となり、誤答の選択肢に一致してしまう。

> **出題** 部品表と正味所要量: H28午前I問28、H30午前I問28 ｜ PLM: H24午前I問28

## 2. 生産方式

### 2.1 かんばん方式

**かんばん方式（ジャストインタイム方式）**は、トヨタ生産方式の中核をなす仕組みである。

> **かんばん方式の運用方法**はどれか。

答えは、

> **前工程は後工程から回ってくるかんばんの指示量に備え、自工程の在庫を最小限に抑えながら生産しておく必要がある。**

**かんばん方式の本質は「後工程引取り方式」**である。前工程が作ったものを後工程に押し込む（プッシュ型）のではなく、**後工程が必要な分だけ前工程に取りに行く（プル型）**。かんばんはその「取りに来た」という指示票である。

```
【従来（プッシュ型）】
  前工程 ──作ったものを押し込む──→ 後工程   ← 使われない在庫が溜まる

【かんばん方式（プル型）】
  前工程 ←──かんばんで指示──── 後工程
       ──必要な分だけ供給──→          ← 必要な分しか作らない
```

誤答として並ぶ記述が、**かんばん方式が否定しているもの**を示している。

| 記述 | なぜ誤りか |
| --- | --- |
| 前工程が生産完了した後、生産量を記載したかんばんとともに部品を**後工程に供給する** | **プッシュ型**であり、かんばん方式の逆 |
| 前工程は後工程の引取り時期や指示量が**大きく変動しても対応できる生産能力の余力をもつ**必要がある | かんばん方式は**生産の平準化**が前提。変動に余力で対応するのではなく、**変動そのものを抑える** |
| 前工程は故障などに備え、**平均故障時間で生産される部品の量を指示量に加算して供給する** | **余分な在庫を持たない**のがジャストインタイムの原則 |

**かんばん方式が成立する条件**は厳しい。生産が平準化されていること、品質が安定していること、設備が故障しないこと、部品が確実に届くこと。どれか一つでも崩れれば、在庫という緩衝材がないため全体が止まる。**在庫は無駄であると同時に、変動を吸収する仕組みでもある**という認識が、この方式を理解する鍵になる。

### 2.2 セル生産方式

> **セル生産方式の利点が生かせる対象**はどれか。

答えは **多種類かつフレキシブルな生産が求められるもの**である。

**セル生産方式は、1人または少人数が複数の工程を担当して製品を組み立てる**方式である。U字型の作業台（セル）を使うことからこの名がある。

| | ライン生産方式 | セル生産方式 |
| --- | --- | --- |
| 分業 | **工程ごとに細分化**（標準化・単純化・専門化） | **1人または少人数が複数工程を担当** |
| 向く生産 | **大量生産、仕様が長期間変わらないもの** | **多種類、フレキシブルな生産** |
| 作業者 | 単純作業に習熟すればよい | **多能工が必要** |
| 切替え | 製品を変えるとライン全体の組替えが要る | **セル単位で柔軟に対応できる** |

誤答はすべて**ライン生産方式が向く対象**である。「大量生産が必要なもの」「仕様が長期間変わらないもの」「標準化、単純化、専門化による分業が必要なもの」はいずれもライン生産の前提になる。

**セル生産が多品種に強いのは、ラインの組替えが不要だから**である。ライン生産では製品を変えるたびに工程の配置を変えなければならないが、セルなら作業手順を変えるだけで対応できる。その代わり、**複数の工程をこなせる多能工を育成する**必要があり、これが導入の難所になる。

> **出題** セル生産方式: H21午前I問28 ｜ かんばん方式: H27午前I問28

## 3. 製品開発の手法

> **CE（コンカレントエンジニアリング）**を説明したものはどれか。

答えは、

> **製品の企画・設計・製造を同時並行処理し、全体のリードタイムを短縮すること。**

**「同時並行処理」「リードタイム短縮」**がキーワードである。

従来は企画 → 設計 → 製造と順に進めていた。しかしこれでは、製造段階で「この形状では作れない」と判明したときに設計からやり直しになる。コンカレントエンジニアリングでは、**設計の段階から製造部門が参加する**ことで、作りやすさを設計に織り込み、手戻りを減らす。

この発想は、[14-6 プロジェクトの時間](../14-project-management/14-6-プロジェクトの時間.md) の**ファストトラッキング**（本来は順次実行する作業を並行実行する）と同じものである。どちらも**並行化によって期間を短縮し、代わりに手戻りのリスクを負う**という構造をもつ。

誤答として並ぶ記述を確認する。

| 記述 | 実際は何か |
| --- | --- |
| CADで設計された図形データを基にNCデータを作成する | **CAM** |
| 生産時点で収集した情報を基に問題を分析し、生産活動の効率向上を図る | **POP**（生産時点情報管理） |
| 製品の開発や生産に関係する情報の中身や表現形式を標準化する | **STEP**などの標準化 |
| **製品の企画・設計・製造を同時並行処理し、全体のリードタイムを短縮する** | **コンカレントエンジニアリング** |

> **出題** コンカレントエンジニアリング: H26午前I問28

## 4. スマートファクトリー

IoTとAIを活用した工場を**スマートファクトリー**という。

> スマートファクトリーで使用される**AIを用いたマシンビジョンの目的**として適切なものはどれか。

答えは **人間の目視検査をAIが代替し、検査効率を向上させる**である。

**マシンビジョン（machine vision）は「機械の視覚」**であり、カメラで撮影した画像をAIが解析して判断する技術である。外観検査、位置決め、寸法測定、文字読取りなどに使われる。

誤答として並ぶのは、いずれも**AIの別の応用**である。

| 記述 | 実際は何か |
| --- | --- |
| 入出荷データを用いてAIが需要予測し、生産数を最適化する | 需要予測（→ [9-5 データベース応用](../09-database/9-5-データベース応用.md) のデータマイニング） |
| VRゴーグルにAIが作業状況に応じたガイドを表示する | AR/VRによる作業支援（→ [8-1 マルチメディア技術](../08-information-media/8-1-マルチメディア技術.md)） |
| 設計変更内容をAIによって整理し、製造現場に正確に伝達する | 情報伝達の支援 |
| **人間の目視検査をAIが代替し、検査効率を向上させる** | **マシンビジョン** |

**「ビジョン（視覚）」という語から、画像を見る用途**だと判断できる。

目視検査がAIに置き換えられるのは、**検査が「見て判断する」繰り返し作業**だからである。熟練者の技能に依存し、疲労によって精度が落ち、人による差も出る。画像認識の精度が人に匹敵する水準に達したことで、置き換えが現実的になった。これは [1-3 情報に関する理論](../01-basic-theory/1-3-情報に関する理論.md) で見た機械学習の応用例にあたる。

> **出題** マシンビジョン: R7午前I問28

## この章のまとめ

- **MRPは生産計画から資材の所要量と発注時期を算出する**。計算では**正味所要量（必要量 − 在庫）を下位に展開する**こと、**同じ部品が複数の経路で使われる**ことに注意する。
- **PLMは製品情報の一元管理（開発からリサイクルまで）**。SCMはモノの流れ、FMSは生産の自動化、MRPは資材計画と、それぞれ対象が違う。
- **かんばん方式は後工程引取り（プル型）**。生産の平準化が前提で、余分な在庫も余力も持たない。
- **セル生産方式は多品種・フレキシブルな生産に向く**。ライン生産は大量生産・仕様固定に向く。
- **コンカレントエンジニアリングは企画・設計・製造の同時並行処理**。ファストトラッキングと同じく、並行化で期間を短縮し手戻りのリスクを負う。
- **マシンビジョンは「機械の視覚」**で、目視検査の代替が代表的な用途になる。
