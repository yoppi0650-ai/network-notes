# 21-1 ビジネスシステム

さまざまな業種・業務で使われる**情報システムの応用形態**を扱う。

この分野に共通するのは、**情報技術が業務の形そのものを変える**という視点である。POSは単なるレジの電子化ではなく、売れ筋を把握して品揃えを変える仕組みになった。同じことが物流、金融、行政でも起きている。本章ではその代表例と、社会全体を見据えた構想を整理する。

午前Iの問27前後から出題される。16年で1問。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、代表的なシステムの整理を補っている。

## 1. 流通・物流のシステム

| システム | 内容 |
| --- | --- |
| **POSシステム** | 販売時点で商品情報を収集する。売上管理だけでなく、**売れ筋・死に筋の把握と発注への反映**が本来の価値 |
| 電子マネー | 現金に代わる決済手段 |
| **トレーサビリティシステム** | 商品の生産から販売までの履歴を追跡できるようにする |
| **ICタグ（RFID）** | 非接触で商品情報を読み取る（→ [6-1 ハードウェア](../06-hardware/6-1-ハードウェア.md)） |
| **GPS応用システム** | 車両の位置を把握し、配送の効率化に使う |

**POSシステムの本質は「データを集めること」ではなく「集めたデータで判断を変えること」**にある。何がいつ売れたかが分かれば、発注量も陳列も品揃えも変えられる。レジを速くするだけなら導入の価値は限られる。

**ICタグがバーコードより優れる点**は、[6-1 ハードウェア](../06-hardware/6-1-ハードウェア.md) で見たとおり、**直接見えなくても読める**こと、**複数を一括で読める**こと、**書換えができる**ことである。この性質が、在庫の棚卸しを一瞬で終わらせたり、生産履歴を個体ごとに追跡したりすることを可能にする。

## 2. 金融・行政のシステム

| システム | 内容 |
| --- | --- |
| 銀行システム | 勘定系（預金・融資）、情報系（分析）、国際系 |
| **フィンテック** | 金融（Finance）と技術（Technology）の融合。決済、送金、資産運用など |
| **電子政府（e-Gov）** | 行政手続のオンライン化 |
| **マイナンバー制度** | 社会保障・税・災害対策の分野で個人を識別する |

金融システムは**止められないシステムの典型**である。[4-1 システムの構成](../04-system-components/4-1-システムの構成.md) で見たミッションクリティカルシステムにあたり、高度な冗長化と厳格な運用が求められる。

## 3. Society 5.0

> 政府は、IoTを始めとする様々なICTが最大限に活用され、**サイバー空間とフィジカル空間とが融合された「超スマート社会」**の実現を推進してきた。必要なものやサービスが人々に過不足なく提供され、年齢や性別などの違いにかかわらず、誰もが快適に生活することができるとされる「超スマート社会」実現への取組は何と呼ばれているか。

答えは **Society 5.0** である。

**「5.0」という番号は、人類社会の発展段階を数えたもの**である。

| 段階 | 社会 |
| --- | --- |
| Society 1.0 | 狩猟社会 |
| Society 2.0 | 農耕社会 |
| Society 3.0 | 工業社会 |
| Society 4.0 | 情報社会 |
| **Society 5.0** | **超スマート社会** |

情報社会（4.0）との違いは、**サイバー空間とフィジカル空間の融合**にある。情報社会では、人が情報を集めて分析し、判断していた。Society 5.0 では、**IoTで現実空間の情報が自動的にサイバー空間へ集まり、AIが分析し、その結果が現実空間へ戻って自動的に作用する**。人が介在しないループが回る点が新しい。

この構造は [4-1 システムの構成](../04-system-components/4-1-システムの構成.md) のエッジコンピューティングや、[6-1 ハードウェア](../06-hardware/6-1-ハードウェア.md) のセンサ・アクチュエータによる制御ループと同じものを、社会規模に拡大したものだといえる。

誤答として並ぶ用語との区別を押さえる。

| 用語 | 内容 |
| --- | --- |
| **e-Gov** | 電子政府の総合窓口。行政手続のポータルサイト |
| **Web 2.0** | 利用者が情報を発信・共有するWebのあり方を指した概念 |
| **ダイバーシティ社会** | 多様性を受け入れる社会。Society 5.0 の理念の一部ではあるが、ICT活用の取組の名称ではない |

> **出題** Society 5.0: R3午前I問27

## この章のまとめ

- **POSシステムの価値は、集めたデータで発注や品揃えの判断を変えること**にある。
- **ICタグは見えなくても読め、一括で読め、書き換えられる**ので、棚卸しやトレーサビリティに効く。
- **Society 5.0 は「サイバー空間とフィジカル空間の融合」**による超スマート社会。情報社会（4.0）との違いは、**人を介さずにループが回る**点にある。
