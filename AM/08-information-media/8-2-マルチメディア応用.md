# 8-2 マルチメディア応用

[8-1 マルチメディア技術](8-1-マルチメディア技術.md) で扱った技術が、実際のサービスや製品でどう使われているかを扱う。

ここでの中心的な論点は**著作権の保護**である。ディジタルコンテンツは劣化なく無限に複製できる。この性質は配布には好都合だが、権利者にとっては致命的でもある。**複製を技術的に制限する仕組み**が必要とされる理由がここにあり、出題もこの点に集中している。

午前IIの問25前後から出題される。16年で1問と出題は少ない。

出題が少ない分野のため、本章では過去問で問われた内容に加えて、応用分野の整理を補っている。

## 1. 著作権保護技術

**DRM（Digital Rights Management）**は、ディジタルコンテンツの利用を技術的に制限する仕組みの総称である。**何を守るか（記録媒体か、伝送路か）**で技術が分かれる。

| 技術 | 保護する対象 |
| --- | --- |
| **CPRM** (Content Protection for **Recordable** Media) | **記録型メディア**（SDメモリカード、録画用DVD／BD）に記録したコンテンツ |
| **CPPM** (Content Protection for **Pre-Recorded** Media) | **あらかじめ記録済み**のメディア（市販のDVD-Audioなど） |
| **DTCP** (Digital **Transmission** Content Protection) | **機器間の伝送**（IEEE 1394、LAN経由） |
| **HDCP** (**High-bandwidth** Digital Content Protection) | **映像出力の伝送**（HDMI、DisplayPort） |

> **SDメモリカードに使用される著作権保護技術**はどれか。

答えは **CPRM** である。

**略語の構成要素から判別できる**のがこの設問の特徴である。

- **Recordable（記録型）** → 利用者が記録するメディア → **SDメモリカード、録画用DVD**
- **Pre-Recorded（記録済み）** → 市販の読出し専用メディア
- **Transmission（伝送）** → 機器から機器への伝送路
- **High-bandwidth（広帯域）** → 広帯域の映像伝送 → **HDMI**

SDメモリカードは利用者がデータを記録するメディアなので、**Recordable を含む CPRM** が対応する。

CPRMの仕組みは、**メディア固有のID（メディアID）と鍵を組み合わせて暗号化する**というものである。これにより、暗号化されたデータを別のメディアにコピーしても、メディアIDが違うため復号できない。地上デジタル放送の「ダビング10」のような制御は、この仕組みの上に成り立っている。

**記録先に紐づけて暗号化する**という発想が、単なるコピー禁止より優れているのは、**正規の利用（自分の機器での再生）は妨げずに、不正な複製だけを無効化できる**点にある。

> **出題** SDメモリカードの著作権保護: R1午前II問25

## 2. 電子透かし

**電子透かし（ディジタルウォーターマーク）**は、

> **画像や音楽などのディジタルコンテンツに、著作権者などの情報を埋め込む**

技術である。

DRMとの違いは**目的**にある。

| | DRM（CPRMなど） | 電子透かし |
| --- | --- | --- |
| 目的 | **複製や再生を制限する** | **流出元を特定する／権利を主張する** |
| 複製 | できない（技術的に制限） | **できてしまう**（制限しない） |
| 知覚 | — | 人には気づかれない |

電子透かしは**複製を防がない**。その代わり、流出したコンテンツから透かしを読み取れば、**誰に配布したものが流出したのかを特定できる**。これが抑止力になる。

技術的には、画像の画素値や音声の波形を、人が気づかない程度に微妙に変化させて情報を埋め込む。[8-1](8-1-マルチメディア技術.md) で見た非可逆圧縮が「知覚されない情報を捨てる」技術だとすれば、電子透かしは「知覚されない領域に情報を足す」技術であり、同じ人間の知覚特性を逆向きに利用している。

電子透かしは、[11-2 情報セキュリティ管理](../11-security/11-2-情報セキュリティ管理.md) でディジタルフォレンジックスの誤答選択肢としても登場する。**「埋め込む」のが電子透かし、「証拠を保全する」のがフォレンジックス**という区別で判別できる。

## 3. マルチメディアの応用分野

| 分野 | 内容 |
| --- | --- |
| ストリーミング配信 | コンテンツをダウンロードしながら再生する。CDNで配信を分散する（→ [10-5 ネットワーク応用](../10-network/10-5-ネットワーク応用.md)） |
| VoIP・ビデオ会議 | 音声・映像をリアルタイムに伝送する（→ [10-5](../10-network/10-5-ネットワーク応用.md)） |
| VR / AR / MR | 仮想世界や拡張現実を提供する（→ [8-1](8-1-マルチメディア技術.md)） |
| CG・映像制作 | 映画、ゲーム、設計の可視化 |
| 画像認識・音声認識 | 機械学習を用いた認識（→ [1-3 情報に関する理論](../01-basic-theory/1-3-情報に関する理論.md)） |
| マシンビジョン | 産業用の画像認識。外観検査や位置決め（→ [21-2 エンジニアリングシステム](../21-business-and-industry/21-2-エンジニアリングシステム.md)） |

**ストリーミング配信がダウンロード配信と違う**のは、全体を受け取る前に再生を始める点である。この方式を成立させるには、再生に先回りしてデータが届き続けなければならない。そのために**バッファリング**（一定量を先読みして蓄える）を行い、ネットワークの瞬間的な遅れを吸収する。それでも追いつかなければ再生が止まる。

ここで効いてくるのが、[10-2 データ通信と制御](../10-network/10-2-データ通信と制御.md) のQoSと、[10-5 ネットワーク応用](../10-network/10-5-ネットワーク応用.md) のジッタである。**平均の帯域が足りていても、到着間隔のばらつき（ジッタ）が大きければ再生は途切れる**。マルチメディアの応用では、帯域だけでなく遅延とその安定性が品質を決める。

---

## この章のまとめ

- 著作権保護技術は**略語の構成要素で判別できる**。**Recordable（記録型メディア）＝CPRM、Pre-Recorded（記録済み）＝CPPM、Transmission（伝送）＝DTCP、High-bandwidth（HDMI）＝HDCP**。**SDメモリカードはCPRM**。
- CPRMは**メディア固有のIDと結び付けて暗号化する**ので、別メディアにコピーしても復号できない。
- **電子透かしは複製を防がない**。流出元を特定するために、知覚されない形で情報を埋め込む。
- ストリーミングの品質は**帯域だけでなく、遅延とジッタ（到着間隔のばらつき）**で決まる。
