# 19-3 ビジネス戦略と目標及び評価

立てた戦略を**具体的な目標に落とし込み、達成度を測る**領域を扱う。

戦略は立てただけでは動かない。「売上を伸ばす」という方針を、「どの指標を、いつまでに、どこまで」という形にしなければ、実行も評価もできない。本章で扱うKGI・CSF・KPIという階層は、**抽象的な方針を測定可能な指標へ降ろしていく**ための道具である。

H21〜R7の午前I・午前IIでは**この小分類からの直接の出題は見当たらなかった**。ただし、バランススコアカードの4視点とKPIの判別（→ [17-1 情報システム戦略](../17-system-strategy/17-1-情報システム戦略.md)、[19-1 経営戦略手法](19-1-経営戦略手法.md)）という形で、関連する内容は繰り返し問われている。

## 1. 目標の階層

戦略から指標へ降りる過程は、3つの階層で整理される。

| 階層 | 内容 | 例 |
| --- | --- | --- |
| **KGI**（重要目標達成指標） | **最終的に達成したい目標**を数値で表す | 「売上高を前年比120%にする」 |
| **CSF**（重要成功要因） | **KGIを達成するために、何が決め手になるか** | 「リピート購入率の向上」 |
| **KPI**（重要業績評価指標） | **CSFの達成度を測る中間的な指標** | 「会員登録者数を月1,000人増やす」 |

```mermaid
graph LR
  A["KGI<br/>達成したい最終目標"] --> B["CSF<br/>何が決め手か"] --> C["KPI<br/>決め手の進捗を測る指標"]
```

**CSFを挟むことに意味がある**。KGIからいきなりKPIを決めようとすると、「測りやすいから」という理由で指標を選んでしまう。**まず「何が成否を分けるのか」を特定し、それを測る指標を選ぶ**という順序でなければ、測っても経営判断に使えない数値が並ぶことになる。

## 2. 指標の設計

### 2.1 良い指標の条件

目標設定の指針として **SMART** がよく挙げられる。

| 要素 | 内容 |
| --- | --- |
| **S**pecific | 具体的である |
| **M**easurable | **測定可能である** |
| **A**chievable | 達成可能である |
| **R**elevant | 目標と関連している |
| **T**ime-bound | 期限がある |

### 2.2 先行指標と遅行指標

| 種類 | 性質 | 例 |
| --- | --- | --- |
| **遅行指標**（結果指標） | 結果が出てから分かる | 売上高、利益率、解約率 |
| **先行指標**（プロセス指標） | **結果より前に動く** | 商談件数、顧客満足度、従業員のスキル習得率 |

**遅行指標だけを見ていては手遅れになる**。売上が落ちてから対策を打っても、原因はすでに数か月前に生じている。先行指標を監視していれば、**結果が出る前に手を打てる**。

[19-1 経営戦略手法](19-1-経営戦略手法.md) のバランススコアカードが4つの視点を設ける理由も、ここにある。財務の視点（遅行指標）だけでなく、学習と成長の視点（先行指標）を同時に見ることで、将来の業績の兆候を捉えられる。

### 2.3 指標が引き起こす行動

指標を設定すると、**人はその指標が良くなるように行動する**。これは狙いどおりでもあり、落とし穴でもある。

- 「問合せの平均対応時間を短縮する」という指標だけを設ければ、**雑に切り上げる**ことで数値は改善する
- 「新規顧客獲得数」だけを追えば、**既存顧客への対応が疎かになる**

**単一の指標で評価すると、測られていない部分が犠牲になる**。バランススコアカードが複数の視点を要求するのも、SLAで項目を絞りつつ偏りを避けるのも（→ [15-1 サービスマネジメント](../15-service-management/15-1-サービスマネジメント.md)）、同じ問題への対処である。

## 3. 評価の枠組み

### 3.1 PDCAによる管理

戦略の実行は、PDCAサイクルで管理する。

| 段階 | 内容 |
| --- | --- |
| Plan | 戦略を立て、KGI・CSF・KPIを設定する |
| Do | 施策を実行する |
| **Check** | **KPIを測定し、目標との差を把握する** |
| Act | 差の原因を分析し、施策または目標を見直す |

**Actで見直すのは施策だけとは限らない**。目標そのものが現実離れしていた、CSFの特定が誤っていた、という可能性もある。前提まで遡って検証できるかどうかが、改善の質を決める。

### 3.2 評価手法との関係

| 手法 | 評価するもの | 参照 |
| --- | --- | --- |
| **バランススコアカード** | 4つの視点から多面的に | [19-1 経営戦略手法](19-1-経営戦略手法.md) |
| ベンチマーキング | 他社との比較 | [19-1](19-1-経営戦略手法.md) |
| ROI、NPV、PBP | 投資の採算性 | [17-1 情報システム戦略](../17-system-strategy/17-1-情報システム戦略.md) |
| 損益分岐点分析 | 採算のとれる売上水準 | [22-3 会計・財務](../22-corporate-activities/22-3-会計-財務.md) |

評価手法はそれぞれ**測れる範囲が限られている**。ROIは金額で測れるものしか扱えず、ベンチマーキングは比較対象のある項目しか見られない。**複数の手法を組み合わせて、測れない部分を補い合う**のが実務的な使い方になる。

## この章のまとめ

- 目標は **KGI（最終目標）→ CSF（成否を分ける要因）→ KPI（進捗を測る指標）**の階層で降ろす。**CSFを挟まないと、測りやすいだけの指標になる**。
- **遅行指標だけでは手遅れになる**。先行指標を併せて監視することで、結果が出る前に手を打てる。
- **単一の指標で評価すると、測られていない部分が犠牲になる**。複数の視点を組み合わせる。
- 評価手法はそれぞれ測れる範囲が限られるので、**組み合わせて補い合う**。
