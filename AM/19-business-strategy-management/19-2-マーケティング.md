# 19-2 マーケティング

**顧客に価値を届け、対価を得る仕組み**を設計する領域を扱う。

## 1. 4Pと4C

**4P**は売り手の視点からマーケティング要素を4つに整理したもので、**4C**はそれを買い手の視点に置き換えたものである。

> 売り手側でのマーケティング要素 **4P** は、買い手側での要素 **4C** に対応するという考え方がある。4Pの一つである**プロモーション**に対応する4Cの構成要素はどれか。

答えは **コミュニケーション（Communication）**である。

対応関係は次のとおりである。

| 4P（売り手の視点） | 4C（買い手の視点） | 意味の転換 |
| --- | --- | --- |
| **Product**（製品） | **Customer Value**（顧客価値） | 「何を作るか」から「顧客にとっての価値は何か」へ |
| **Price**（価格） | **Customer Cost**（顧客コスト） | 「いくらで売るか」から「顧客が負担する総コストは何か」へ |
| **Place**（流通） | **Convenience**（利便性） | 「どこで売るか」から「顧客にとって買いやすいか」へ |
| **Promotion**（販売促進） | **Communication**（コミュニケーション） | 「どう知らせるか」から「顧客とどう対話するか」へ |

**4Cへの置き換えには明確な思想がある**。4Pはすべて売り手が「する」ことを並べたもので、顧客は働きかけの対象でしかない。4Cは同じ要素を顧客の側から見直す。

たとえば Promotion → Communication の転換は、**一方的に知らせる活動から、双方向のやり取りへ**という発想の変化を表している。広告を流すだけでなく、顧客の声を聞き、関係を築くことが販売促進の本質だと捉え直している。

Price → Customer Cost も同様で、顧客が払うのは価格だけではない。店まで行く時間、比較検討の手間、使い方を覚える労力も含めた**総コスト**が購買の判断材料になる。

**覚え方**としては、**頭文字が同じもの（Product → Customer Value は例外）**と考えるより、**Pは売り手の行動、Cは買い手の受け取り方**という対応で理解したほうが応用が利く。

## 2. 市場の捉え方

### 2.1 STP

マーケティング戦略の基本的な手順である。

| 段階 | 内容 |
| --- | --- |
| **S：セグメンテーション** | 市場を似た特性をもつ集団に分割する |
| **T：ターゲティング** | どの集団を狙うかを決める |
| **P：ポジショニング** | 狙った集団の中で、競合とどう差別化するかを決める |

**すべての顧客を満足させようとすると、誰も満足させられない**という認識がこの手順の前提にある。市場を分け、狙いを絞り、その集団に対して明確な位置を占める、という順で考える。

### 2.2 市場セグメントの基準

| 基準 | 例 |
| --- | --- |
| 地理的 | 国、地域、都市規模、気候 |
| 人口統計的 | 年齢、性別、職業、所得 |
| 心理的 | ライフスタイル、価値観 |
| 行動的 | 購買頻度、ロイヤリティ、使用場面 |

### 2.3 マーケティング手法

| 手法 | 内容 |
| --- | --- |
| マスマーケティング | 市場全体に同じ製品を同じ方法で提供する |
| ターゲットマーケティング | 特定のセグメントに絞る |
| **ワントゥワンマーケティング** | 個々の顧客に合わせて個別に対応する |
| **顧客ロイヤルティ** | 顧客が継続的に選び続ける度合い |

**ワントゥワンマーケティングが現実的になったのは情報技術による**。顧客ごとの購買履歴を蓄積し分析できるようになって初めて、一人ひとりに合わせた提案ができる。これを支える仕組みが**CRM**であり、[19-4 経営管理システム](19-4-経営管理システム.md) で扱う。

## 3. プロダクトライフサイクル

製品が市場に投入されてから姿を消すまでを4段階で捉える枠組みである。

| 段階 | 売上 | 利益 | 戦略 |
| --- | --- | --- | --- |
| **導入期** | 小さい | 赤字 | 認知を広げる。価格より普及を優先 |
| **成長期** | 急増 | 増加 | 生産能力を拡大し、シェアを確保する |
| **成熟（市場飽和）期** | 頭打ち | 最大だが競争激化 | 差別化、コスト削減、市場の細分化 |
| **衰退期** | 減少 | 減少 | 撤退または縮小の判断 |

```
売上
  │           ／＼
  │        ／      ＼＿＿＿
  │     ／                 ＼
  │  ／                       ＼
  └──────────────────────────────→ 時間
   導入期  成長期   成熟期    衰退期
```

**各段階で取るべき戦略が異なる**のがこの枠組みの実用的な意味である。成長期に価格競争を仕掛ければ、まだ伸びる市場で利益を削ることになる。成熟期に生産能力を拡大すれば、過剰設備を抱える。**いまどの段階にいるかの判断が、戦略の前提になる**。

[19-1 経営戦略手法](19-1-経営戦略手法.md) のPPMとも対応している。導入期から成長期の製品が「問題児」や「花形」、成熟期が「金のなる木」、衰退期が「負け犬」にあたる。

また、[20-1 技術開発戦略の立案](../20-technology-strategy-management/20-1-技術開発戦略の立案.md) の**技術のSカーブ**も同じS字の形をとるが、**縦軸が売上ではなく技術の進歩度**である点が違う。設問では両者が入れ替えられることがあるので、何を測っているかを確認する。

## 4. 価格戦略

| 戦略 | 内容 | 適する場面 |
| --- | --- | --- |
| **スキミングプライシング（上澄み吸収価格）** | **当初は高価格に設定し、徐々に下げる** | 競合が少なく、価格感度の低い層がいる。開発費を早期に回収したい |
| **ペネトレーションプライシング（市場浸透価格）** | **当初から低価格に設定する** | 早期にシェアを獲得したい。規模の経済が効く |
| キャプティブ価格戦略 | 本体を安く、消耗品で利益を得る | プリンタとインク、ゲーム機とソフト |
| フリーミアム | 基本機能は無料、高度な機能は有料 | ソフトウェア、Webサービス |

**スキミングとペネトレーションは正反対の戦略**だが、どちらが正しいというものではない。

- 模倣されにくく、価格を気にしない顧客層がいるなら、**高く売って早く回収する**（スキミング）
- 模倣されやすく、先行者がシェアを取れば優位が固まるなら、**安く売って早く広げる**（ペネトレーション）

判断の分かれ目は、**競合がどれだけ速く追随できるか**と、**規模が優位につながるか**である。[19-1 経営戦略手法](19-1-経営戦略手法.md) のファイブフォース分析で見た「新規参入の脅威」が、この判断に直結する。

## この章のまとめ

- **4Pは売り手の視点、4Cは買い手の視点**。**Promotion に対応するのは Communication**で、「一方的に知らせる」から「双方向に対話する」への転換を表す。
- マーケティング戦略は **セグメンテーション → ターゲティング → ポジショニング**の順。すべてを狙えば誰も満足させられない。
- プロダクトライフサイクルは**導入期・成長期・成熟期・衰退期**。段階によって取るべき戦略が変わる。
- 価格戦略は**スキミング（高く始めて下げる）とペネトレーション（安く始めてシェアを取る）**。競合の追随速度と規模の経済の有無で選ぶ。
