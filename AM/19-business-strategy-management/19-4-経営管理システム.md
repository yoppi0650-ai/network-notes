# 19-4 経営管理システム

経営を支える**情報システムの類型**を扱う。ERP、SCM、CRM、SFA といった略語が主な題材である。

これらのシステムは、**どの範囲の、何を最適化するか**で区別できる。社内の経営資源を統合するのがERP、取引先を含むモノの流れを最適化するのがSCM、顧客との関係を管理するのがCRMである。略語を丸暗記するより、**対象範囲と目的**で整理したほうが確実に判別できる。

午前Iの問25〜27前後から出題される。16年で4問。

## 1. 主な経営管理システム

**対象範囲**で並べると関係が見える。

| システム | 対象範囲 | 目的 |
| --- | --- | --- |
| **ERP** | **社内の経営資源全体** | 基幹業務を統合管理し、経営を効率化する |
| **SCM** | **調達先から販売先まで（企業間を含む）** | モノの流れを最適化する |
| **CRM** | **顧客との関係** | 顧客満足度と顧客ロイヤルティを高める |
| **SFA** | 営業活動 | 営業プロセスを可視化し、効率化する |
| MRP | 製造の資材所要量 | 必要な資材を必要な時期に手配する（→ [21-2 エンジニアリングシステム](../21-business-and-industry/21-2-エンジニアリングシステム.md)） |

```
        ← SCM（企業間のモノの流れ） →
調達先 ──→ 【自社：ERP（経営資源の統合）】 ──→ 顧客
                                            ← CRM（顧客との関係）→
```

**ERPが社内、SCMが上流（調達側）、CRMが下流（顧客側）**という位置関係で覚えると、設問の説明文がどれを指すかを判別しやすい。

## 2. ERP

**ERP（Enterprise Resource Planning）**は、

> **企業の経営資源を有効に活用して経営の効率を向上させるために、基幹業務を部門ごとではなく統合的に管理するための業務システム**

である。

対象となる基幹業務は、会計、人事、製造、購買、在庫管理、販売などである。

**「部門ごとではなく統合的に」**という点がERPの核心である。部門ごとにシステムを作ると、同じデータが各所に重複し、部門をまたぐ集計に手間がかかる。たとえば受注情報が販売システムにしかなければ、生産計画を立てるのに転記が要り、転記のたびにずれが生じる。ERPは**データを1か所に統合する**ことでこれを解消する。

ERPの導入が難しいのは、**パッケージに業務を合わせる必要がある**ためである。各社の個別の業務手順に合わせて改修すれば、統合の利点が失われ、保守も困難になる。そのため導入時には**フィット＆ギャップ分析**（パッケージの機能と自社の要求がどれだけ適合し、どれだけ乖離しているかの分析）を行い、業務の側を標準に寄せる判断が求められる。これは [17-2 業務プロセス](../17-system-strategy/17-2-業務プロセス.md) のBPRと一体で進めることになる。

## 3. SCM

**SCM（Supply Chain Management）**は、

> **部品や資材の調達から製品の生産、流通、販売までの、企業間を含めたモノの流れを適切に計画・管理し、最適化して、リードタイムの短縮、在庫コストや流通コストの削減などを実現しようとする考え方**

である。

別の設問では、

> **生産、在庫、購買、販売、物流などの全ての情報をリアルタイムに交換することによって、サプライチェーン全体の効率を大幅に向上させる経営手法**

と表現されている。

### 3.1 企業間にまたがることの意味

**SCMの特徴は「企業間を含める」点**にある。自社の在庫だけを最適化しても、サプライチェーン全体では非効率が残る。

典型的な問題が**ブルウィップ効果**である。小売の需要がわずかに変動しただけで、卸、メーカ、部品メーカと上流に遡るほど発注量の振れ幅が増幅する。各社が「念のため」に安全在庫を上乗せするためで、**各社が個別に合理的な判断をした結果、全体では過剰在庫になる**。

これを防ぐには、**実需の情報を全体で共有する**しかない。SCMが「情報をリアルタイムに交換する」ことを求めるのは、このためである。

### 3.2 SCMの改善指標

> **サプライチェーンマネジメントの改善指標**となるものはどれか。

答えは **不良在庫の減少率**である。

SCMの目的が**在庫コストと流通コストの削減、リードタイムの短縮**である以上、改善指標も在庫に関するものになる。

誤答との区別を押さえる。

| 記述 | 何の指標か |
| --- | --- |
| 残業時間の減少率 | 労務管理・業務効率 |
| 販売単価下落の防止率 | 価格戦略（→ [19-2 マーケティング](19-2-マーケティング.md)） |
| **不良在庫の減少率** | **SCM** |
| 優良顧客数の増加率 | **CRM** |

**「在庫」「リードタイム」「物流コスト」に関する指標ならSCM**と判別できる。

> **出題** SCMの改善指標: H22午前I問25 ｜ SCM: H26午前I問26

## 4. CRM

**CRM（Customer Relationship Management）**は、

> **企業内の全ての顧客チャネルで情報を共有し、サービスのレベルを引き上げて顧客満足度を高め、顧客ロイヤリティの最大化に結び付ける考え方**

である。

### 4.1 「全てのチャネルで情報を共有する」ことの意味

**この一句がCRMの要点**である。顧客は店舗、電話、Web、メールと複数の窓口を使い分ける。それぞれが独立して記録を持っていれば、顧客は窓口を変えるたびに同じ説明を繰り返すことになる。

情報を共有すれば、**どの窓口でも顧客の状況を把握したうえで対応できる**。問合せ履歴を踏まえた提案も、購買履歴に基づく案内もできるようになる。[19-2 マーケティング](19-2-マーケティング.md) で触れたワントゥワンマーケティングは、この基盤の上に成り立つ。

**顧客ロイヤルティの最大化**を目的とするのは、**新規顧客の獲得より既存顧客の維持のほうが費用対効果が高い**という認識による。獲得には広告や販促の費用がかかるが、既存顧客は適切な関係を保てば継続して購入する。

### 4.2 誤答との区別

CRMの設問では、他の経営管理システムの説明が並ぶ。

| 記述 | 実際は何か |
| --- | --- |
| 卸売業者・メーカが、小売店の経営活動を支援してその売上と利益を伸ばすことによって、自社との取引拡大につなげる方法 | **リテールサポート** |
| 企業全体の経営資源を有効かつ総合的に計画して管理し、経営の高効率化を図るための手法 | **ERP** |
| **全ての顧客チャネルで情報を共有し、顧客満足度を高め、顧客ロイヤリティの最大化に結び付ける** | **CRM** |
| 生産、在庫、購買、販売、物流などの全ての情報をリアルタイムに交換し、サプライチェーン全体の効率を向上させる | **SCM** |

**判別の手がかりは対象範囲**である。「経営資源全体」ならERP、「サプライチェーン」ならSCM、「顧客」ならCRMと判断できる。

> **出題** CRM: H29午前I問26、R1午前I問27

## この章のまとめ

- 経営管理システムは**対象範囲**で区別する。**ERPは社内の経営資源、SCMは企業間のモノの流れ、CRMは顧客との関係**。
- **ERPの核心は「部門ごとではなく統合的に」**。導入時はパッケージに業務を合わせる判断が求められる。
- **SCMが企業間にまたがるのは、個別最適が全体最適にならない**から。実需情報の共有がブルウィップ効果を防ぐ。改善指標は**在庫・リードタイム・物流コスト**に関するもの。
- **CRMの要点は「全ての顧客チャネルで情報を共有する」**こと。新規獲得より既存顧客の維持のほうが費用対効果が高いという前提に立つ。
