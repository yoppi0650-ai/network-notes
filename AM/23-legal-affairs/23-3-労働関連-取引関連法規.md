# 23-3 労働関連・取引関連法規

**人を働かせるときのルール**と、**企業どうしが取引するときのルール**を扱う。

システム開発は、自社の社員だけで完結することがほとんどない。請負で外部に委託し、派遣で人を受け入れ、さらに下請に再委託する。このとき、**誰が誰に指示を出せるのか**、**代金をいつどう決めるのか**が法律で定まっている。これを踏み外すと、技術的には何も問題がなくても違法になる。

午前Iの問30から出題される。16年で2問と多くはないが、[23-1 知的財産権](23-1-知的財産権.md) の著作権の帰属や、[14-10 プロジェクトの調達](../14-project-management/14-10-プロジェクトの調達.md) の契約形態と密接に関わるため、まとめて理解しておく価値がある。

## 1. 契約形態と指揮命令関係

外部の技術者に働いてもらう方法は、大きく三つある。契約の**法律上の分類**は [14-10 プロジェクトの調達](../14-project-management/14-10-プロジェクトの調達.md) と [18-3 調達計画及び実施](../18-system-planning/18-3-調達計画及び実施.md) で扱ったので、ここでは**指揮命令がどこから出るか**という軸で整理する。

| 契約形態 | 雇用関係 | **指揮命令を出すのは** | 完成責任 |
| --- | --- | --- | --- |
| **請負** | 受注者と技術者 | **受注者**（発注者は指示できない） | **あり** |
| **準委任** | 受注者と技術者 | **受注者**（発注者は指示できない） | なし |
| **労働者派遣** | 派遣元と技術者 | **派遣先** | なし |

```mermaid
graph LR
  subgraph 請負・準委任
    A1[発注者] -->|業務の委託| B1[受注者]
    B1 -->|指揮命令| C1[技術者]
  end
  subgraph 労働者派遣
    A2[派遣先] -->|派遣契約| B2[派遣元]
    B2 -->|雇用| C2[派遣労働者]
    A2 -->|指揮命令| C2
  end
```

**図の違いが、この章のすべての出発点になる**。請負では発注者から技術者へ向かう矢印が存在しない。派遣では、**雇用は派遣元、指揮命令は派遣先**という二重の関係が生じる。

この違いが、[23-1 知的財産権](23-1-知的財産権.md) で見た著作権の帰属（請負は発注先、派遣は派遣先）の根拠でもある。**誰の指揮命令下で創作したかが帰属を決める**からである。

## 2. 労働者派遣法

### 2.1 派遣元と派遣先の役割分担

労働者派遣では**雇用と指揮命令が分離する**ため、どちらが何に責任をもつかを法律が細かく定めている。

> **労働者派遣法**において、**派遣元事業主**の講ずべき措置等として定められているものはどれか。

答えは **労働者の教育訓練の機会の確保など、福祉の増進**である。

主な措置を、派遣元と派遣先に分けて整理する。

| 措置 | 派遣元 | 派遣先 |
| --- | --- | --- |
| **労働者の教育訓練・キャリア形成支援、福祉の増進** | **○** | |
| 派遣労働者であることの明示、就業条件の明示 | ○ | |
| **派遣元責任者**の選任、**派遣元管理台帳**の作成 | ○ | |
| 社会保険・労働保険の適用 | ○ | |
| **派遣先責任者**の選任、**派遣先管理台帳**の作成 | | **○** |
| 指揮命令者や関係者への**派遣契約内容の周知** | | **○** |
| 就業環境の整備、苦情の処理 | | ○ |

**誤答の三つは、いずれも派遣先の措置**である。「派遣先管理台帳」「派遣先責任者」は名前に「派遣先」とあるので判別しやすい。「派遣労働者を指揮命令する者やその他関係者への派遣契約内容の周知」も、**指揮命令するのは派遣先**なので派遣先の措置だと分かる。

**正解を見分ける原理は「雇用主としての責任か、使用者としての責任か」**である。教育訓練やキャリア形成、福祉の増進は、**雇用している者＝派遣元**が負う。一方、現場での指揮命令や就業環境に関わるものは、**実際に働かせている者＝派遣先**が負う。この切り分けを押さえれば、台帳や責任者の名称を暗記していなくても判断できる。

### 2.2 その他の主な規制

| 規制 | 内容 |
| --- | --- |
| **派遣禁止業務** | **港湾運送、建設、警備、病院等における医療**の各業務は、原則として派遣できない |
| **期間制限** | 同一の事業所に対する派遣は原則**3年**が上限。同一の組織単位に同一の派遣労働者を派遣するのも原則3年 |
| **日雇派遣の原則禁止** | 30日以内の雇用契約による派遣は原則として禁止 |
| **二重派遣の禁止** | 派遣された労働者をさらに他社へ派遣することはできない |
| **事前面接の禁止** | 派遣先が派遣労働者を**特定することを目的とする行為**（事前面接、履歴書の送付要求など）は禁止 |

**事前面接の禁止**は、現場感覚とずれやすいので注意したい。派遣は「人を選んで雇う」仕組みではなく「必要な業務に人を充てる」仕組みなので、**誰が来るかを派遣先が選ぶことは制度の前提に反する**。紹介予定派遣（直接雇用を前提とする派遣）だけが例外として事前面接を認められている。

> **出題** 労働者派遣法: R5午前I問30

## 3. 偽装請負

**契約書は請負なのに、実態は派遣**という状態を**偽装請負**という。

| 典型的な兆候 | なぜ問題か |
| --- | --- |
| **発注者が受注者の技術者に直接作業指示を出す** | 請負では発注者に指揮命令権がない |
| 発注者が技術者の**勤務時間や休暇を管理する** | 労務管理は受注者の役割 |
| 発注者が技術者の**配置や作業割当てを決める** | 同上 |
| 受注者が**技術者を供給するだけ**で、業務の遂行に責任をもっていない | 請負の実体がない |

偽装請負が禁じられるのは、形式を整えることで**派遣法や労働基準法上の責任を誰も負わなくなる**からである。発注者は「請負だから雇用責任はない」と言い、受注者は「現場に任せている」と言う。その結果、労働者だけが保護の外に置かれる。

**実務上の対処**は、現場に受注者側の責任者を置き、**発注者からの要求はその責任者を通す**ことである。技術的な調整であっても、発注者が直接メンバーに指示を出す形にしない。どうしても直接のやり取りが必要な体制なら、はじめから準委任ではなく**派遣契約にする**のが筋である。

## 4. 労働基準法と関連法

| 法律 | 主な内容 |
| --- | --- |
| **労働基準法** | 労働時間（原則1日8時間・週40時間）、休憩、休日、割増賃金、**36協定**（時間外労働の労使協定）、解雇の予告 |
| **労働安全衛生法** | 安全衛生管理体制、**ストレスチェック**、健康診断 |
| **労働契約法** | 労働契約の成立・変更の原則、**有期労働契約の無期転換**（通算5年超） |
| **男女雇用機会均等法** | 募集・採用・配置・昇進における性別を理由とする差別の禁止 |
| **育児・介護休業法** | 育児休業・介護休業の権利、短時間勤務制度 |

情報処理の文脈で押さえておきたいのが**裁量労働制**と**フレックスタイム制**である。

| 制度 | 仕組み | 適用 |
| --- | --- | --- |
| **フレックスタイム制** | 一定期間の**総労働時間**を定め、**始業・終業時刻を労働者が決める**。コアタイムを設けることもある | 業務の種類による制限はない |
| **専門業務型裁量労働制** | **実際の労働時間にかかわらず、あらかじめ定めた時間だけ働いたとみなす** | **情報処理システムの分析・設計**など、法令で定められた業務に限る |
| **企画業務型裁量労働制** | 同上 | 事業運営の企画・立案・調査・分析業務 |

**裁量労働制が「みなし」である点**が重要である。何時間働いても所定のみなし時間として扱われるため、**業務の進め方を労働者の裁量に委ねられる業務**にしか適用できない。プログラミングの実装作業そのものは、専門業務型の対象業務（システムの分析・設計）には含まれないと解されている。

## 5. 下請代金支払遅延等防止法

### 5.1 法律の目的と構造

**下請法**は、**親事業者が取引上の優位な立場を使って下請事業者に不利益を押し付けること**を防ぐ法律である。独占禁止法の補完として機能する。

適用されるかどうかは、**取引の種類と資本金の組合せ**で決まる。情報成果物作成委託（プログラムの作成など）やサービス提供委託では、たとえば親事業者が資本金5,000万円超で下請事業者が5,000万円以下、といった区分が定められている。

親事業者の義務と禁止行為を整理する。

| 区分 | 内容 |
| --- | --- |
| **義務** | **書面（3条書面）の交付**、取引記録の書類の作成・保存、**支払期日を定める義務**（納品後60日以内）、遅延利息の支払 |
| **禁止行為** | 受領拒否、**支払遅延**、**下請代金の減額**、返品、**買いたたき**、購入・利用強制、報復措置、有償支給原材料等の対価の早期決済、割引困難な手形の交付、不当な経済上の利益の提供要請、**不当な給付内容の変更・やり直し** |

**禁止行為は「下請事業者に責任がなくても」成立する**点が特徴である。たとえば支払遅延は、下請事業者が同意していても違法になる。これは、同意それ自体が優位な立場によって引き出された可能性があるためで、**形式的な合意では免責されない**構造になっている。

### 5.2 禁止されている行為の判断

> ユーザから請け負うソフトウェア開発を下請業者に委託する場合、**下請代金支払遅延等防止法で禁止されている行為**はどれか。

答えは、

> **下請業者に委託する業務内容は決まっているが、ユーザとの契約代金が未定なので、下請代金の取決めをユーザとの契約決定後にする。**

> **OCRについての注記**: この設問の選択肢は、OCR結果に文字化けが多く含まれている。ここでは判読可能な部分と下請法の規定から各選択肢の趣旨を再構成して説明しているが、**原文の正確な文言は確認できていない**。正解の記号（イ）と、下請法の考え方そのものは確実である。

判断の軸は、**親事業者側の都合で下請代金の決定を先送りしていないか**である。

| 趣旨 | 可否 | 理由 |
| --- | --- | --- |
| 経費について具体的な金額を明記せず、**実費負担する旨を発注書面に記載**する | **適法** | 具体的な金額を記載できないやむを得ない事情があれば、**算定方法を記載する**ことが認められる |
| **業務内容は決まっているのに、ユーザとの契約代金が未定だから下請代金の取決めを後回しにする** | **禁止** | **親事業者側の事情**であり、下請事業者に委託する内容が確定している以上、代金を定めて書面を交付しなければならない |
| 発注書面を交付する代わりに、**下請業者の承諾を得て**、必要な事項を記載した電子メールで発注する | **適法** | **下請事業者の承諾があれば電磁的方法による提供が認められる** |
| やむを得ない事情で業務内容の一部が未定なので、**その部分と下請代金は別途取り決める** | **適法** | 正当な理由で定められない事項は記載を要しないが、**定まったら直ちに書面を交付する**必要がある |

**適法な三つと違法な一つを分けるのは、「誰の都合か」と「確定しているか」**である。

- **業務内容が未確定**なら、代金を決められないのは当然であり、別途定めてよい（4つ目）。
- **業務内容が確定している**のに代金を決めないのは、親事業者側の事情にすぎない（2つ目）。これが禁止される。

つまり、**下請事業者が何をすべきか決まった時点で、いくら払うかも決めなければならない**。ユーザとの契約がまとまるまで待つというのは、**自社のリスクを下請に転嫁している**ことになる。

書面交付が電子メールでもよいのは、**下請事業者の承諾**という条件が付いているからである。書面交付義務の目的は、取引条件を証拠として残して後の紛争を防ぐことにあり、電磁的記録でもその目的は達せられる。

> **出題** 下請代金支払遅延等防止法: H30午前I問30

## 6. 取引関連のその他の法規

| 法律 | 内容 |
| --- | --- |
| **独占禁止法** | 私的独占、不当な取引制限（カルテル、入札談合）、**不公正な取引方法**（優越的地位の濫用など）を禁止 |
| **民法** | 契約の一般原則。**契約不適合責任**（旧・瑕疵担保責任）、債務不履行、[14-10 プロジェクトの調達](../14-project-management/14-10-プロジェクトの調達.md) で扱った請負・委任の規定 |
| **商法・会社法** | 商取引の特則、会社の機関設計（→ [22-1 経営・組織論](../22-corporate-activities/22-1-経営-組織論.md)） |
| **製造物責任法（PL法）** | 製造物の**欠陥**により生じた損害の賠償責任。**ソフトウェア単体は「製造物」に当たらない**が、組込み機器は対象になりうる |
| **資金決済法** | 前払式支払手段（プリペイド）、資金移動業、暗号資産の規制（→ [21-3 eビジネス](../21-business-and-industry/21-3-eビジネス.md)） |
| **特定商取引法** | 通信販売における**広告表示義務**、誇大広告の禁止 |
| **電子契約法** | 電子消費者契約における**操作ミスによる錯誤の救済**、承諾通知の到達時に契約が成立すること |

**製造物責任法でソフトウェア単体が対象外**とされるのは、PL法の「製造物」が**動産**（形のある物）と定義されているためである。ただし、ソフトウェアを組み込んだ機器が欠陥により事故を起こせば、**その機器の製造業者が責任を負う**。組込みシステムを扱う場合（→ [21-5 産業機器](../21-business-and-industry/21-5-産業機器.md)）に関係してくる。

**電子契約法の錯誤救済**も押さえておきたい。通常の民法では、重大な過失があった側は錯誤を理由に契約を取り消せない。しかし電子商取引では、**事業者が確認画面を用意していなかった場合、消費者の操作ミスによる申込みを無効にできる**。これが、オンラインショップに必ず確認画面がある理由である。

## この章のまとめ

- 請負・準委任では**指揮命令は受注者から**出る。派遣では**雇用は派遣元、指揮命令は派遣先**に分かれる。この違いが著作権の帰属（→ [23-1 知的財産権](23-1-知的財産権.md)）も決める。
- 派遣元の措置は**雇用主としての責任**（教育訓練、福祉の増進、派遣元責任者・台帳）、派遣先の措置は**使用者としての責任**（派遣先責任者・台帳、契約内容の周知、就業環境）。
- **偽装請負**は、契約は請負でも発注者が直接指示を出している状態。責任の所在が消えるため禁止される。
- **裁量労働制は「みなし労働時間」**の制度で、適用できる業務が法令で限定されている。
- 下請法では、**業務内容が確定しているのに親事業者側の都合で代金の取決めを先送りすること**が禁止される。書面交付は**下請事業者の承諾があれば電磁的方法でもよい**。
- **PL法の「製造物」は動産**なので、ソフトウェア単体は対象外。組込み機器は対象になりうる。
