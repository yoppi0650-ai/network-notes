# 23-2 セキュリティ関連法規

**情報セキュリティと個人情報の保護を支える法律**を扱う。

技術的な対策をどれだけ積んでも、**攻撃者を処罰する根拠**や**情報を預かる側の義務**が法律で定まっていなければ、社会の仕組みとしては成立しない。[11-1 情報セキュリティ](../11-security/11-1-情報セキュリティ.md) 以降で見た技術は、この章の法律と組み合わせて初めて機能する。

午前Iの問30に、**ほぼ毎年この分野から1問**出題される。16年で6問。法律名と内容の対応を問う形式が中心で、条文の暗記ではなく**その法律が何を守ろうとしているか**を理解していれば解ける。

## 1. 法律の全体像

セキュリティ関連法規は、**何を守るか**で整理すると見通しがよくなる。

| 守るもの | 法律 | 中心的な内容 |
| --- | --- | --- |
| **コンピュータへのアクセス** | **不正アクセス禁止法** | 他人のID・パスワードでの不正ログインとその助長行為を処罰 |
| **データ・システムそのもの** | **刑法** | 不正指令電磁的記録（ウイルス）、電子計算機損壊等業務妨害、電磁的記録不正作出 |
| **企業の秘密・信用** | **不正競争防止法** | 営業秘密の侵害、ドメイン名の不正取得 |
| **個人の情報** | **個人情報保護法** | 取得・利用・提供のルール、安全管理措置 |
| **国全体の備え** | **サイバーセキュリティ基本法** | 国・自治体・事業者の責務、戦略本部の設置 |
| **電子的な意思表示** | **電子署名法** | 電子署名に押印と同様の法的効力を与える |
| **通信の秘密** | **電気通信事業法** | 通信事業者の守秘義務、検閲の禁止 |

試験で問われるのは、**ある行為がどの法律に引っかかるか**、あるいは**ある法律が何を対象にしているか**である。

## 2. 不正アクセス禁止法

> 利用権限をもたない第三者が、**他人のIDやパスワードを使ってネットワークに接続されたコンピュータを利用可能にする行為及びその助長行為**を処罰の対象にしている法律はどれか。

答えは **不正アクセス禁止法**である。

この法律の構造を理解しておく。

| 禁止行為 | 内容 |
| --- | --- |
| **不正アクセス行為** | 他人の識別符号（ID・パスワード）を無断で入力する、またはセキュリティホールを突いて**アクセス制御機能を回避して利用可能にする** |
| **識別符号の不正取得** | 他人のID・パスワードを不正に取得する |
| **不正アクセスを助長する行為** | 他人のID・パスワードを**第三者に提供する** |
| **識別符号の不正保管** | 不正に取得したID・パスワードを保管する |
| **識別符号の入力を不正に要求する行為** | **フィッシング**。正規サイトを装ってID・パスワードを入力させる |

**押さえるべき点が二つある。**

第一に、**「利用可能にした」時点で成立する**。実際に中のデータを見たり壊したりしなくても、ログインに成功すれば不正アクセス行為になる。これは、侵入そのものを独立に処罰することで、**被害が発生する前の段階で抑止する**という考え方による。

第二に、**助長行為も処罰される**。他人のパスワードを掲示板に書き込むだけで、自分はアクセスしていなくても罪に問われる。[11-4 情報セキュリティ対策](../11-security/11-4-情報セキュリティ対策.md) で見たような攻撃の多くは、まず認証情報の流通から始まる。その流通自体を断つための規定である。

また、**ネットワークを経由したアクセスが前提**である。スタンドアロンの端末を直接操作する行為はこの法律の対象外になる（別の罪に問われる可能性はある）。

誤答として並ぶ法律を確認する。

| 法律 | 内容 |
| --- | --- |
| **刑法** | ウイルス作成・供用、電子計算機損壊等業務妨害などを規定（→ [3章](#3-刑法のサイバー犯罪規定)）。ただし**他人のIDでのログインそのものを直接処罰する規定はない** |
| **通信傍受法** | **捜査機関が**犯罪捜査のために通信を傍受する手続きを定めた法律。処罰法ではない |
| **電気通信事業法** | 電気通信事業者の**業務の規律**を定めた法律。通信の秘密の保護、検閲の禁止などを含む |

> **出題** 不正アクセス禁止法: H21午前I問30

## 3. 刑法のサイバー犯罪規定

不正アクセス禁止法が「入ること」を罰するのに対し、**刑法は「壊すこと・騙すこと・作ること」を罰する**。

| 罪名 | 対象となる行為 |
| --- | --- |
| **不正指令電磁的記録に関する罪**（いわゆるウイルス作成罪） | 正当な理由なく、**他人のコンピュータで意図に反する動作をさせる不正なプログラムを作成・提供・供用・取得・保管**する |
| **電子計算機損壊等業務妨害罪** | コンピュータやデータを破壊する、虚偽の情報を与えるなどして**業務を妨害**する |
| **電子計算機使用詐欺罪** | コンピュータに虚偽の情報を与えて**財産上の不法な利益を得る** |
| **電磁的記録不正作出・供用罪** | 権利義務に関する**電磁的記録を不正に作る**、またはそれを使う |

**不正指令電磁的記録に関する罪は「作っただけ」でも成立する**点が特徴である。実際に感染させて被害を出す前の段階で処罰する構造は、不正アクセス禁止法と同じ発想に立っている。ただし「正当な理由なく」という要件があるので、**ウイルス対策の研究や検体の解析は対象にならない**。

## 4. 不正競争防止法

### 4.1 営業秘密の三要件

> 不正競争防止法において、**営業秘密となる要件**は、「秘密として管理されていること」「事業活動に有用な技術上又は営業上の情報であること」と、**もう一つ**はどれか。

答えは **公然と知られていないこと**である。

営業秘密の三要件を整理する。

| 要件 | 名称 | 意味 |
| --- | --- | --- |
| 秘密として管理されていること | **秘密管理性** | アクセス制限、秘密表示など、**秘密として扱う意思が客観的に認識できる状態** |
| 事業活動に有用な技術上又は営業上の情報であること | **有用性** | 事業に役立つ情報であること（違法行為の隠蔽情報などは除く） |
| **公然と知られていないこと** | **非公知性** | 保有者の管理下以外では**一般に入手できない**こと |

**この三つがすべて揃って初めて営業秘密として保護される**。とりわけ**秘密管理性**が実務上の争点になりやすい。社内で誰でも見られる状態に置いていた情報は、たとえ重要な技術情報でも営業秘密と認められない可能性がある。これが、[11-2 情報セキュリティ管理](../11-security/11-2-情報セキュリティ管理.md) で見た情報資産の分類・ラベル付けやアクセス権管理が、単なる運用上の良習慣ではなく**法的保護の前提条件**になる理由である。

誤答の選択肢（営業譲渡が可能なこと／期間が10年を超えないこと／特許出願をしていること）は、いずれも要件ではない。とくに**「特許出願をしていること」は正反対**である。営業秘密は**出願せずに秘匿する**ことで守る方法であり、出願すれば公開されて非公知性を失う。この対比は [13-2 知的財産適用管理](../13-software-development-management/13-2-知的財産適用管理.md) の「特許化するか、ノウハウとして秘匿するか」という判断につながる。

### 4.2 不正競争行為

> 不正競争防止法の**不正競争行為に該当するもの**はどれか。

答えは、

> **商標権のない商品名を用いたドメイン名を取得し、当該商品のコピー商品を販売し、利益を取得した。**

ドメイン名に関する不正競争行為の要件は、**図利加害目的**（不正の利益を得る目的、または他人に損害を加える目的）で、他人の**特定商品等表示と同一または類似のドメイン名**を取得・保有・使用することである。

各選択肢を要件に当てはめる。

| 記述 | 該当 | 理由 |
| --- | --- | --- |
| 競争関係にないB社が**偶然に**A社の社名に類似のドメイン名を取得した | **非該当** | **図利加害目的がない**。偶然の一致は対象外 |
| ある地方だけで有名な和菓子に類似した商品名の飲料を、**その和菓子が有名ではない地方で**販売した | **非該当** | 周知性は地域ごとに判断される。**知られていない地域では混同が生じない** |
| **商標権のない商品名のドメイン名を取得し、コピー商品を販売して利益を得た** | **該当** | **コピー商品の販売という図利加害目的が明確**。商標権がなくても不正競争防止法で規制される |
| 他社サービスと類似しているが、自社サービスに適しており、**正当な利益を得る目的があると認められる**ドメインを取得して利用した | **非該当** | **正当な目的があれば図利加害目的に当たらない** |

**「商標権がなくても規制される」**という点が、この問題の最大のポイントである。[23-1 知的財産権](23-1-知的財産権.md) で見たとおり商標権は登録して初めて発生するが、不正競争防止法は**登録の有無に関係なく、実際の混同や不正な利益追求を規制する**。登録していない事業者も、周知性があれば保護を受けられる。

もう一つの軸が**目的の有無**である。同じ「類似ドメインの取得」でも、偶然なら非該当、正当な目的があれば非該当、コピー商品の販売目的なら該当になる。**行為の外形だけでは判断できず、目的を見る**のがこの法律の特徴である。

> **出題** 不正競争防止法と営業秘密: H26午前I問30 ｜ 不正競争防止法: R6午前I問30

## 5. 個人情報保護法

### 5.1 基本的な仕組み

個人情報保護法は、**個人情報取扱事業者**に対して次の義務を課す。

| 場面 | 義務 |
| --- | --- |
| **取得** | **利用目的を特定**し、**通知または公表**する。偽りその他不正の手段による取得の禁止 |
| **利用** | **特定した利用目的の範囲内**でのみ利用する。範囲を超えるには**本人の同意**が必要 |
| **保管** | **安全管理措置**を講じる。従業者・委託先の監督 |
| **第三者提供** | 原則として**本人の同意**が必要（**子会社・関連会社も「第三者」**） |
| **開示等の請求** | 本人からの開示、訂正、利用停止の請求に応じる |

**個人情報**とは、生存する個人に関する情報であって、**特定の個人を識別できるもの**（他の情報と容易に照合して識別できるものを含む）、または**個人識別符号**（指紋データ、マイナンバー、免許証番号など）を含むものをいう。

**要配慮個人情報**（人種、信条、病歴、犯罪歴など）は、**取得の時点で本人の同意が必要**であり、オプトアウトによる第三者提供も認められない。

### 5.2 適法な行為の判断

> **特段の措置をとらずになされた**個人情報取扱事業者の行為のうち、個人情報保護法に照らして**適法な行為**はどれか。

答えは、

> **Webサイトの問合せページで「自社製品販売促進ダイレクトメール送付可否欄」に「可」と記入した依頼者の氏名及び住所を、自社の製品販売促進用ダイレクトメール発送先住所録に登録した。**

**「可」と記入した時点で、本人がその利用目的に同意している**。したがって利用目的の範囲内であり、適法である。

誤答を一つずつ検討すると、この法律の判断軸がはっきりする。

| 記述 | 違法となる理由 |
| --- | --- |
| **商品企画立案を目的として**回収したアンケートの氏名・住所を、**販売促進DM発送先**に登録した | **利用目的外の利用**。「商品企画立案」と伝えて取得したものを販売促進に使っている |
| 自社が主催した勉強会の参加者リストを、**自社の子会社の**メールマガジン発送先に登録した | **第三者提供にあたる**。**子会社も別法人なので「第三者」**であり、本人の同意が要る |
| 従業員が参加した**同窓会で配布された同窓生名簿**の氏名・電話番号を、自社のコールセンタ用リストに登録した | **取得の経緯が不適切**で、かつ本人は事業者に情報を提供した覚えがない。利用目的の通知もない |

**三つの誤答が、それぞれ異なる義務に違反している**ことに注目したい。1つ目は**利用目的の制限**、2つ目は**第三者提供の制限**、3つ目は**適正取得と利用目的の通知**である。

とくに**「子会社も第三者」**は実務でも間違えやすい点である。グループ企業だから自由にやり取りできる、ということはない。共同利用として扱うには、共同利用する旨・項目・範囲・目的・管理責任者を**あらかじめ本人に通知または公表**しておく必要がある。設問が「特段の措置をとらずに」と断っているのは、この手続きを踏んでいないことを示している。

> **出題** 個人情報保護法: H23午前I問30

## 6. サイバーセキュリティ基本法

> サイバーセキュリティ基本法において、**サイバーセキュリティの対象として規定されている情報**の説明はどれか。

答えは、

> **電磁的方式によって、記録、発信、伝送、受信される情報に限られる。**

この法律は、**サイバーセキュリティ**を「電磁的方式により記録・発信・伝送・受信される情報の漏えい、滅失、毀損の防止その他の安全管理のために必要な措置」などと定義している。

**ポイントは、対象を情報の「形式」で定めている**ことである。

| 選択肢 | なぜ誤りか |
| --- | --- |
| **外交、国家安全に関する機密情報に限られる** | 内容による限定はない。民間の事業情報も対象 |
| **公共機関で処理される対象の手書きの書類に限られる** | **手書きの書類は電磁的方式ではない**ので対象外 |
| **個人の属性を含むプライバシー情報に限られる** | 個人情報に限定されない。それは個人情報保護法の役割 |
| **電磁的方式によって、記録、発信、伝送、受信される情報に限られる** | **正しい** |

**「内容ではなく形式で区切る」**という理解が、この問題を解く鍵になる。国家機密か個人情報かビジネス情報かを問わず、**電磁的に扱われる情報であれば等しく対象になる**。逆に、紙の書類は（どれほど重要でも）この法律のサイバーセキュリティの定義には含まれない。

法律の主な内容も押さえておく。

- 国、地方公共団体、重要社会基盤事業者、サイバー関連事業者、教育研究機関、**国民**それぞれの責務を定める
- 内閣に**サイバーセキュリティ戦略本部**を設置する
- 政府は**サイバーセキュリティ戦略**を策定する

> **出題** サイバーセキュリティ基本法: H27午前I問30

## 7. 電子署名法

> **電子署名法に関する記述**のうち、適切なものはどれか。

答えは、

> **電子署名には、民事訴訟法における押印と同様の効力が認められる。**

紙の文書では、本人の押印や署名があれば**真正に成立したものと推定される**（民事訴訟法）。電子署名法は、**一定の要件を満たす電子署名にも同じ推定効を与える**。これにより、電子契約を紙の契約と同等に扱えるようになった。

**法律の役割は「技術を定めること」ではなく「法的効力を与えること」**である。この視点で誤答を見ると、いずれも対象や手段を不当に狭めていることが分かる。

| 記述 | なぜ誤りか |
| --- | --- |
| 電子署名には、**電磁的記録ではなく、かつ、コンピュータで処理できないものも含まれる** | 電子署名は**電磁的記録に記録された情報について行われる措置**である。コンピュータで処理できないものは含まれない |
| 電子署名の認証業務を行うことができるのは、**政府が運営する認証局に限られる** | **民間の認証事業者も認定を受けて業務を行える**。認定認証業務の制度がある |
| 電子署名は**共通鍵暗号技術によるものに限られる** | 技術は限定されていない。実際には**公開鍵暗号を用いたデジタル署名**が主流である（→ [11-5 セキュリティ実装技術](../11-security/11-5-セキュリティ実装技術.md)） |

**最後の選択肢が技術的に最も誤っている**ことは、[11-1 情報セキュリティ](../11-security/11-1-情報セキュリティ.md) の内容から判断できる。共通鍵は送受信者が同じ鍵を共有するため、**署名者本人しか作れないことを第三者に証明できない**。本人性の証明には、秘密鍵で署名し公開鍵で検証する公開鍵暗号方式が必要になる。法律が特定の技術を指定していないのは、技術の進歩に対応するためだが、**実際に要件を満たせるのは公開鍵暗号ベースの方式である**。

> **出題** 電子署名法: R3午前I問30

## 8. その他の関連法

出題実績はないが、誤答の選択肢や周辺知識として押さえておきたい法律を挙げる。

| 法律 | 内容 |
| --- | --- |
| **プロバイダ責任制限法**（情報流通プラットフォーム対処法） | 権利侵害情報が流通した際の**プロバイダの損害賠償責任の制限**と、**発信者情報の開示請求**の手続きを定める |
| **特定電子メール法** | **広告宣伝メールの送信には原則として事前の同意（オプトイン）が必要**。送信者情報の表示義務、受信拒否の通知先の明示 |
| **刑事訴訟法** | 電磁的記録の差押え、記録命令付差押えなどの捜査手続き |
| **マイナンバー法**（番号利用法） | 個人番号の利用範囲を**法定された事務に限定**し、収集・保管を厳しく制限する |
| **電波法** | 無線局の免許、技術基準適合証明。無線LAN機器の技適マークの根拠（→ [10-1 ネットワーク方式](../10-network/10-1-ネットワーク方式.md)） |

**特定電子メール法のオプトイン原則**は、[5.2](#52-適法な行為の判断) で見た個人情報保護法の「可と記入した人にだけDMを送る」という処理とも整合する。両方の法律が、**本人が明示的に同意した場合にだけ送ってよい**という同じ結論を支えている。

## この章のまとめ

- **不正アクセス禁止法**は、他人のID・パスワードでの**不正ログインとその助長行為**を処罰する。**利用可能にした時点で成立**し、ネットワーク経由であることが前提。
- **刑法**は、ウイルスの作成・供用、業務妨害、電磁的記録の不正作出を罰する。**作っただけでも成立する**。
- **営業秘密の三要件は秘密管理性・有用性・非公知性**。アクセス制御やラベル付けは、法的保護の前提条件になる。
- **不正競争防止法は商標権がなくても規制する**。ドメイン名については**図利加害目的の有無**が判断の軸になる。
- 個人情報保護法では、**利用目的の制限・第三者提供の制限・適正取得**が三本柱。**子会社も「第三者」**である。
- **サイバーセキュリティ基本法は、情報を内容ではなく「電磁的方式」という形式で区切る**。手書きの書類は対象外。
- **電子署名法は電子署名に押印と同様の推定効を与える**。認証業務は民間でも行え、技術は限定されていないが、実際には公開鍵暗号方式による。
