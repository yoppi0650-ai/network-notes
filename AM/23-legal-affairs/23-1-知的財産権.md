# 23-1 知的財産権

**知的な創作や営業上の信用を保護する権利**を扱う。

情報処理の文脈でこの分野が重要なのは、**ソフトウェアが何重にも権利の対象になる**からである。ソースコードは著作物、実装されたアルゴリズムは発明、製品名は商標、画面デザインは意匠になりうる。どの権利がどう働くかを知らなければ、他者の権利を侵害するか、自社の権利を守り損ねる。

午前Iの問17・問30前後、午前IIの問25前後から出題される。16年で9問。**著作権の原始的帰属が3回**出題されている。

## 1. 権利の全体像

| 分類 | 権利 | 保護するもの | 取得 |
| --- | --- | --- | --- |
| **産業財産権** | 特許権 | 発明（高度な技術的思想） | **出願・審査・登録** |
| | 実用新案権 | 考案（物品の形状等） | 出願・登録（無審査） |
| | 意匠権 | 物品のデザイン | 出願・審査・登録 |
| | 商標権 | 商品・サービスの標識 | 出願・審査・登録 |
| **著作権** | 著作権 | 思想・感情の創作的表現 | **創作と同時に自動発生** |
| その他 | 営業秘密 | 秘密管理された有用な情報 | 不正競争防止法による（→ [23-2 セキュリティ関連法規](23-2-セキュリティ関連法規.md)） |

**産業財産権は出願が必要、著作権は自動発生**という違いが基本になる。この違いから、[13-2 知的財産適用管理](../13-software-development-management/13-2-知的財産適用管理.md) で見た「特許がなくても著作権に基づいて使用許諾できる」という帰結が導かれる。

## 2. 産業財産権

> 日本において、**産業財産権と総称される四つの権利**はどれか。

答えは **意匠権、実用新案権、商標権、特許権**である。

**著作権は産業財産権に含まれない**。これが設問の唯一の論点で、選択肢には必ず著作権を混ぜたものが並ぶ。

産業財産権が4つとも**特許庁に出願して登録を受ける**のに対し、著作権は登録を要しない。この手続きの違いが、両者を分ける基準になっている。

> **出題** 産業財産権: H28午前I問30

## 3. 特許権

### 3.1 特許権の基本的な性質

> **特許権に関する記述**のうち適切なものはどれか。

答えは、

> **A社が特許を出願するより前に独自に開発して発売した製品は、A社の特許権の侵害にならない。**

これは**先使用権**と呼ばれる制度による。出願より前から善意で実施していた者は、その後に他社が特許を取っても、実施を継続できる。**出願時点ですでに世の中にあったものまで独占させるのは不合理**だからである。

誤答として並ぶ記述を確認する。

| 記述 | なぜ誤りか |
| --- | --- |
| 組込み機器におけるハードウェアは特許権で保護されるが、**ソフトウェアは保護されない** | **ソフトウェア関連発明も特許の対象になる** |
| 審査を受けて特許権を取得した後に、**特許権が無効となることはない** | **無効審判によって無効になりうる**。審査には見落としがある |
| **先行特許と同一の技術であっても、独自に開発した技術であれば侵害にならない** | **誤り**。[3.1](#31-特許権の基本的な性質) の先使用権は**出願より前から実施していた**場合に限られる。出願後に独自開発しても侵害になる |

**最後の選択肢と正解の違い**が重要である。どちらも「独自に開発した」と書かれているが、**出願より前か後か**が分かれ目になる。特許は**先に出願した者に与えられる**（先願主義）ので、後から独自に到達しても権利は得られない。

この性質が、[13-2 知的財産適用管理](../13-software-development-management/13-2-知的財産適用管理.md) で見た「リバースエンジニアリングで技術が容易に明らかになる場合は特許化すべき」という判断の根拠になる。秘匿していても他社が独自に到達して特許を取れば、こちらが使えなくなる恐れがある。

### 3.2 新規性の喪失

> 開発した製品で利用している新規技術に関して特許の出願を行った。日本において**特許権の取得が可能なもの**はどれか。

答えは、

> **顧客と守秘義務の確認を取った上で技術内容を説明した後、製品発表前に出願した。**

特許の要件のひとつが**新規性**である。**出願前に公然と知られた発明には特許が与えられない**。したがって、公開してしまった後の出願は原則として認められない。

各選択肢を新規性の観点で確認する。

| 記述 | 可否 | 理由 |
| --- | --- | --- |
| **学会で技術内容を発表した日から11か月目に出願した** | **不可** | 発表により新規性を喪失。救済制度（新規性喪失の例外）はあるが、適用には所定の手続きと期間の制限がある |
| **守秘義務の確認を取った上で説明した後、製品発表前に出願した** | **可** | **守秘義務の下での開示は「公然」ではない**ので新規性を失わない |
| 製品に使用した**暗号の生成式**を出願した | 不可 | **数式そのものは「自然法則を利用した技術的思想」に当たらず**、発明として認められない |
| **製品を販売した後に出願した** | 不可 | 販売により公然実施となり、新規性を喪失 |

**「守秘義務があれば公然ではない」**という点が正解の鍵である。秘密保持契約を結んだ相手への開示は、不特定多数への公開ではないので新規性を損なわない。これは実務上も重要で、顧客との事前の擦り合わせは守秘義務の下で行い、出願を済ませてから公表する、という順序が取られる。

> **出題** 特許権の新規性喪失: H21午前II問25 ｜ 特許権: H22午前I問17

## 4. 著作権

### 4.1 保護の対象

著作権は**思想・感情の創作的表現**を保護する。アイデアそのものは保護しない。

> **Webページの著作権に関する記述**のうち適切なものはどれか。

答えは、

> **特定の分野ごとにWebページのURLを収集し、簡単なコメントをつけたリンク集は、著作権法で保護される。**

リンク集が保護されるのは、**素材の選択または配列に創作性があれば編集著作物として保護される**という規定による。URL自体は事実にすぎないが、「どの分野のどのページを選び、どう並べ、どうコメントするか」に創作性があれば、その全体が著作物になる。

誤答として並ぶ記述を確認する。

| 記述 | なぜ誤りか |
| --- | --- |
| 営利目的でなく個人のWebページに他人の著作物を無断掲載しても、**私的使用であるから侵害とならない** | **Webページでの公開は私的使用ではない**。私的使用は個人的または家庭内での使用に限られる |
| フリーウェアとして公開したプログラムは、**著作権法による保護の対象とならない** | **無償公開でも著作権は存在する**（→ [5-5 オープンソースソフトウェア](../05-software/5-5-オープンソースソフトウェア.md)） |
| 試用期間中のシェアウェアを使用して作成したデータを、試用期間終了後もWebページに掲載することは侵害に当たる | **作成したデータは利用者の著作物**であり、ソフトウェアの試用期間とは関係がない |

**「公開すれば私的使用ではない」**という点が、1つ目の誤答の核心である。私的使用の範囲は著作権法で狭く定められており、インターネットでの公開は明確にその外にある。

### 4.2 適法な行為と侵害行為

> プログラムの著作物について、著作権法上**適法である行為**はどれか。

答えは、

> **処理速度を向上させるために、購入したプログラムを改変した。**

プログラムの所有者は、**自ら実行するために必要と認められる限度で複製・翻案（改変）できる**と定められている。処理速度の向上を目的とした改変は、この範囲に含まれる。

誤答として並ぶ行為を確認する。

| 記述 | なぜ違法か |
| --- | --- |
| **海賊版を複製したプログラムと事前に知りながら入手し、業務で使用した** | **違法複製物と知りながら業務上使用すれば侵害とみなされる** |
| 業務処理用に購入したプログラムを複製し、社内教育用に各部門に配布した | **複製権の侵害**。社内でも配布は複製にあたる |
| 職務著作のプログラムを、作成した担当者の独断で複製し、他社に貸与した | **職務著作の著作者は法人**なので、担当者に処分の権限はない |
| **処理速度を向上させるために、購入したプログラムを改変した** | **適法**（自ら実行するために必要な範囲の改変） |

[13-2 知的財産適用管理](../13-software-development-management/13-2-知的財産適用管理.md) で見た「契約で複製権の許諾を受けていないのにプロテクトを外して複製した」という事例も、同じ枠組みで判断できる。**所有者に認められる複製・改変は「自ら実行するために必要な限度」であり、契約で制限されていればそれに従う**。

> **出題** Webページの著作権: H25午前I問30 ｜ プログラムの著作物と適法行為: R1午前I問30

## 5. 著作権の帰属

**3回出題されている**重要テーマである。

### 5.1 委託開発の場合

> A社は、B社と著作物の権利に関する**特段の取決めをせず**、A社の要求仕様に基づいて、販売管理システムのプログラム作成をB社に依頼（委託）した。この場合の**プログラム著作権の原始的帰属**はどうなるか。

答えは **B社に帰属する**である。

**著作権は創作した者に発生する**のが原則である。要求仕様を出したのはA社でも、プログラムを実際に作成したのはB社なので、著作権はB社に生じる。

**費用を負担した側に帰属するのではない**という点が、この問題の核心である。発注者は成果物を使うことはできても、複製して他に流用するには受注者の許諾が要る。[13-2 知的財産適用管理](../13-software-development-management/13-2-知的財産適用管理.md) で見たとおり、これを避けるには**契約で帰属を明記する**しかない。

「A社とB社が話し合って決定する」「A社とB社で共有する」という選択肢も誤りである。**原始的帰属は法律で定まる**ものであり、取決めがなければ自動的に創作者に帰属する。話し合いや共有が必要なら、そう契約しておかなければならない。

### 5.2 請負と派遣の違い

> 企業が**請負**で受託して開発したか、又は**派遣契約**によって派遣された社員が開発したプログラムの著作権の帰属に関し**契約に定めがないとき**、著作権の原始的な帰属はどうなるか。

答えは **請負の場合は発注先に帰属し、派遣の場合は派遣先に帰属する**である。

| 契約形態 | 帰属先 | 理由 |
| --- | --- | --- |
| **請負** | **発注先（受注した会社）** | 受注者が自らの判断と責任で作成するため |
| **派遣** | **派遣先** | 派遣社員は**派遣先の指揮命令下**で職務として作成するため（職務著作） |

**派遣で派遣先に帰属するのは「職務著作」の規定による**。法人の発意に基づき、その業務に従事する者が職務上作成した著作物は、法人が著作者になる。派遣社員は派遣先の指揮命令を受けて働くので、この条件を満たす。

**判断の軸は「誰の指揮命令下で作ったか」**である。請負では受注会社が自ら判断して作るので受注会社に、派遣では派遣先の指示で作るので派遣先に帰属する。派遣元に帰属することはない。

> **出題** プログラム著作権の原始的帰属: H22午前I問30、R4午前I問30 ｜ 請負・派遣と著作権の帰属: H29午前I問30

## 6. 生成AIと著作権

> 著作権法及び関連法令によれば、**生成AIを利用して画像を生成する行為又はその生成物の利用が著作権侵害にあたるか否か**に関して適切な記述はどれか。

答えは、

> **AIを利用して生成した画像が著作権で保護された既存の画像と類似しており、それを公開した場合、著作権侵害となる可能性がある。**

**「可能性がある」という慎重な表現**が正解の特徴である。生成AIと著作権の関係は、場合によって結論が変わる。

| 論点 | 考え方 |
| --- | --- |
| **AIの学習段階** | 情報解析を目的とする利用は、一定の条件下で権利者の許諾なく行える |
| **生成・利用段階** | **通常の著作権侵害と同じ基準**で判断される。既存の著作物との**類似性**と**依拠性**が問われる |
| **生成物の著作物性** | **人による創作的寄与があれば著作物になりうる**。AIが自動生成しただけなら認められにくい |

**極端な断定を含む選択肢は誤り**になる。

| 記述 | なぜ誤りか |
| --- | --- |
| 著作権で保護された画像を学習している場合、そのAIを利用すると**いかなる場合も著作権侵害になる** | **学習したこと自体は侵害にならない**。生成物が類似していなければ問題は生じない |
| 生成した画像は**いかなる状況でも著作権の対象外**となり、侵害の懸念は生じない | **人の創作的寄与があれば著作物になりうる**し、既存著作物と類似すれば侵害になりうる |
| **既存の画像と類似しており、公開した場合、著作権侵害となる可能性がある** | **適切** |

**学習段階と生成・利用段階を分けて考える**のが、この問題を理解する鍵である。学習は広く認められる一方、**生成物が既存の著作物と似ていれば、AIを使ったかどうかに関係なく侵害が成立しうる**。道具が何であれ、結果として他人の表現を複製すれば侵害になる、という原則は変わらない。

> **出題** 生成AIと著作権: R7午前I問30

## この章のまとめ

- **産業財産権は特許・実用新案・意匠・商標の4つ**。**著作権は含まれない**。産業財産権は出願が必要、著作権は自動発生する。
- 特許は**先願主義**。出願**前**から実施していれば先使用権で保護されるが、出願**後**に独自開発しても侵害になる。
- **守秘義務の下での開示は「公然」ではない**ので新規性を失わない。学会発表や製品販売の後では原則として出願できない。
- **リンク集は編集著作物として保護されうる**。Webページでの公開は私的使用ではない。**無償公開でも著作権は存在する**。
- 著作権の原始的帰属は**創作した者**。**委託開発では受注者、請負では発注先、派遣では派遣先**（職務著作）。費用を出した側ではない。
- 生成AIでは**学習段階と生成・利用段階を分けて考える**。生成物が既存著作物と類似すれば、**AIを使ったかどうかに関係なく侵害が成立しうる**。
